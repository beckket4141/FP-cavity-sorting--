# 理论价值重估：从解析分支到工程有效工作点

## 1. 结论先行

本轮更新后，连续满载 `S_N={1,\dots,N}` 的理论骨架不变，但工程筛选口径更贴近当前器件事实：

1. 解析最优结构仍是
   \[
   s_{\min}^{\max}=1/N,\quad k^*=m/N,\quad \gcd(m,N)=1.
   \]
2. 计算模型按**晶体整体腔**处理，不再默认空气腔：
   - `lambda0 = 795 nm`（真空波长）
   - `n = 1.453371`（石英在 795 nm）
   - `lambda_medium = lambda0 / n`
3. `w0` 由硬淘汰改为软分档告警，不再因 `w0` 单项直接淘汰分支。

## 2. 当前筛选口径（2026-03-16）

在 `engineering_screening_common.py` 中，几何与质量两层筛选为：

- 几何硬约束：
  - `L >= L_min`
  - `w_curved <= w_curved_max`
- `w0` 软分档（不硬淘汰）：
  - `comfortable`: `w0 >= 50 um`
  - `experimental_ok`: `47 um <= w0 < 50 um`
  - `high_risk`: `w0 < 47 um`
- 质量层：
  - `tau_eff >= tau0`
  - `platform_exists == yes`
  - `Delta L >= Delta L_min`

4. 不宜写：
   “`N=9` 只剩唯一分支 `m=2`（与筛选口径无关）。”

## 6. 理论价值的更准确定位

这套方法的价值不在“公式复杂”，而在“链路完整”：

- 解析分支给出候选集合；
- 几何筛选决定哪些分支可做；
- `tau/F` 再决定可做分支是否真的够用；
- 对非连续集合再由 MIS 扩展处理。

因此，`k^*=m/N` 是理论骨架，不是工程终点。
