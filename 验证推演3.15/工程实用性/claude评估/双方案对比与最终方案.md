## 一、两个方案的核心共识

两方案在以下关键判断上完全一致：

1. **以N为第一锚点，F为第二锚点** —— 先几何再光谱
2. **工程筛选在τ之前** —— 几何可行性是独立于精细度的约束
3. **MIS降级** —— 连续集是主线，非连续集是扩展
4. **解析解的价值不在公式本身** —— 而在它引出的多分支选型和工程约束问题

这个共识已经很强了。下面讨论差异。

## 二、实质性差异

### 2.1 工程筛选是§5.1的subsection还是独立一节？

| | Claude方案 | GPT方案 |
|--|-----------|---------|
| 工程筛选位置 | §5.1.6（§5.1的最后一个subsection） | 独立的"第二层"（隐含为独立section） |

**分析**：

GPT把它提升为独立一层（"第二层"），逻辑上更清楚——确实，"纯数学最优"和"工程可行性筛选"是两个独立的论证步骤。但在论文排版上，独立成section会面临一个问题：这部分内容量不大（1-1.5页），独立成节会显得单薄。

**最终建议**：保持作为§5.1的subsection（§5.1.6或§5.1.7），但在行文中明确标注这是"第二步筛选"。具体做法：

- §5.1.5 标题："连续满载的解析最优结构"（不变）
- §5.1.6 标题："解析分支的工程可行性筛选"（新增）
- §5.1.6 开头第一句就说清楚："上一节给出的 φ(N)/2 个数学等价分支在物理上并不等价。本节从腔体稳定性的角度对这些分支进行工程筛选。"

这样在逻辑上是"两步"，在排版上是同一节的两个subsection，篇幅匹配。

### 2.2 "三者交汇"是否需要独立成节？

| | Claude方案 | GPT方案 |
|--|-----------|---------|
| 三者交汇 | 独立§5.3"设计空间的完整刻画" | 隐含在"第三层"中，与τ讨论合并 |

**分析**：

Claude方案把容量极限、平台裕度、设计流程图抽出来单列§5.3。GPT方案把它们留在τ讨论的后半部分。

两种都可以，但我现在倾向于**GPT的做法更紧凑**。理由：

- 容量极限 M_max = ⌊F/τ₀⌋ 本质上就是τ判据的直接推论（把 s_min ≥ δ 和 s_min^max = 1/N 合并就得到）
- 平台裕度也是δ和1/N的差
- 把它们留在τ那一节，作为"τ判据的设计层面推论"，逻辑链更短

但需要在§5.2末尾加一个**小结段落**，显式地画出三者交汇的完整图景——就是我之前写的那个约束图。这个段落不长（半页），但起到"画龙点睛"的作用。

**最终建议**：不单列§5.3。容量极限和平台裕度留在§5.2。但在§5.2末尾新增一个subsection（如§5.2.7"设计空间的完整约束结构"），用约束图+设计流程总结全局。

### 2.3 术语纪律：ER vs SNR

GPT明确指出"别太早切到信噪比(SNR)，以ER为主术语"。

**这个建议是正确的。** 理由：
- 当前论文全文用ER_max和ER_sum作为性能指标，已经建立了完整的语境
- SNR是系统级概念，涉及暗计数、源态纯度等器件外因素——论文已明确声明不讨论这些
- 引入SNR需要额外定义一层（SNR = signal/noise，noise包含什么？），会稀释主线
- e_sort已经作为连接ER和QKD的桥梁存在，不需要再加一个SNR

**结论**：全文坚持ER为主术语。e_sort作为QKD接口。不引入SNR。

## 六、§5.1.6（新增）的草稿要点

标题：**解析分支的工程可行性筛选**

核心论证线：

> 上一节指出，连续满载问题 S_N 的解析最优分支为 k* = m/N（gcd(m,N)=1），
> 共 φ(N)/2 个。这些分支在数学上等价——都给出 s_min = 1/N。
> 但它们对应不同的几何比 (L/R)* = sin²(πm/N)，
> 而不同的 L/R 在腔体稳定性、对准灵敏度和基模参数上有显著差异。

内容要素：

1. **稳定性约束的物理根据**（2-3句）
   - 平凹腔 g 参数 = 1-L/R
   - L/R→0 时 g→1，腔极短，机械对准困难
   - L/R→1 时 g→0，接近共心，失准灵敏度 ~1/(1-g) 发散

2. **N=9 的三分支对比表**（已有数据）
   - m=1: L/R=0.117, L=2.9mm, g=0.883, 灵敏度8.5× → 不实用
   - m=2: L/R=0.413, L=10.3mm, g=0.587, 灵敏度2.4× → 最佳折中
   - m=4: L/R=0.970, L=24.2mm, g=0.030, 灵敏度1.0× → 不实用（近共心）

3. **N=12 反例**（关键段落）
   - φ(12)=4, 但 m<N/2 且 gcd(m,12)=1 的只有 m=1,5
   - m=1: L/R=0.067 → 腔长1.67mm，完全不实用
   - m=5: L/R=0.933 → 近共心，g=0.067，完全不实用
   - 结论：即使精细度足够，N=12 在标准平凹腔中无工程可行的解析分支

4. **一般趋势的汇总表**（选取N=5,7,9,10,12,15,20,30）
   - 列出：N, φ(N)/2, 工程可行数, 典型可行L/R
   - 突出N=12的"零可行分支"

5. **小结**（2-3句）
   - m=1 对所有 N≥10 均不实用（L<2.5mm）
   - 工程可行分支数远少于数学分支数
   - 因此，解析最优公式的价值不在于告诉你"s_min=1/N"（这很简单），
     而在于列举所有候选工作点并支持基于工程约束的择优

## 七、§5.2.7（新增）"设计空间的完整约束结构"草稿要点

这是"三者交汇"的显式表述，放在§5.2的最后一个subsection。

内容：

1. **约束图**（文字版或TikZ图）
```
输入: F（硬件）, τ₀（质量底线）, R（腔镜）, 目标N
  |
  ├─→ 容量检查: N ≤ ⌊F/τ₀⌋ ? 若否→提高F或降低τ₀
  |
  ├─→ 列出解析分支: k*=m/N, gcd(m,N)=1, m<N/2
  |
  ├─→ 几何筛选: (L/R)*=sin²(πm/N) ∈ 实用窗口 ?
  |
  ├─→ 平台裕度: ΔL = f(1/N-δ, m, N, R) ≥ 装调公差 ?
  |
  └─→ 输出: 最终工作点 (L/R)*, 预期 τ_eff, ER_sum, e_sort
```

2. **三者制约关系的一段文字总结**：
   - F通过M_max限定N的上限——限定了解析解可用的分母
   - F通过δ限定平台宽度——限定了解析解的工程容差
   - 解析解通过L/R反过来约束可用分支——某些N在任何F下都无工程可行解（如N=12）
   - τ₀的选择则连接了应用需求（如QKD的QBER阈值）与腔体设计

3. **精细度外推**（简短一段）
   - F=30→M_max=10, F=100→M_max=33, F=300→M_max=100
   - 提高F不仅增加容量，还展宽所有现有分支的平台
   - 但高F带来的实际限制（镀膜困难、热效应）超出本文范围
