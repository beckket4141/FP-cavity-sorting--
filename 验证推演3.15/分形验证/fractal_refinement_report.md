# `s_min` 景观的“分形感”验证

## 1. 问题重述

用户的直觉是：

> 当 `M` 变大时，景观是否像是小 `M` 景观的分形扩展？
> 也就是，大轮廓先保留，小轮廓下面再不断长出更细的细节。

对图 2 这类连续满载集合 `S_M = {1,2,...,M}`，最适合先在 Gouy step `k` 变量下分析，因为此时公式最干净，而 `L/R = sin^2(pi k)` 只是一个单调坐标变换，不改变“谁在谁下面”的嵌套关系。

---

## 2. 精确数学形式

对连续集合 `S_M = {1,2,...,M}`，

```math
s_M(k) = s_{\min}(k; S_M) = \min_{1 \le q \le M-1} \|qk\|,
```

其中 `||x||` 表示到最近整数的距离。

这个式子有一个非常关键的直接推论：

```math
s_{M_2}(k)
= \min \Bigl(s_{M_1}(k), \min_{M_1 \le q \le M_2-1}\|qk\|\Bigr),
\quad M_2 > M_1.
```

所以对每一个固定的 `k`，都有

```math
s_{M_2}(k) \le s_{M_1}(k).
```

这说明大 `M` 景观确实是小 `M` 景观的**下包络细化**：

- 小 `M` 的全部约束仍然保留；
- 大 `M` 只是额外加入更多 `q`，从而在原有轮廓下方继续“刻槽”。

换句话说，你的“大轮廓保留，下面长出细节”这个判断，核心方向是对的。

---

## 3. 为什么它“像分形”

这种“像分形”的视觉来源，主要有三层：

1. `s_M(k)` 本身是很多锯齿函数 `||qk||` 的逐点最小值；
2. 每增加一个新的 `q`，就会在旧包络下方切出新的、更窄的凹槽；
3. 因而随着 `M` 增大，同一大峰内部会继续出现更细的子峰和更尖的谷。

这是一种非常典型的**层级细化**或**算术嵌套**结构。

---

## 4. 但它不是严格意义上的“分形自相似”

如果要说“严格分形”或“严格自相似”，目前这组景观还不够。

原因有三条：

### 4.1 固定 `M` 时，它只是分段线性曲线

对每个固定 `M`，`s_M(k)` 是有限条线段拼起来的包络线，拐点数虽然会很多，但仍是有限的。它不是那种无限层级、无限不可微的标准分形曲线。

### 4.2 新细节不是由单一缩放比复制出来的

真正的自相似要求：

- 放大后能看到同一种母图形反复复制；
- 各层复制 obey 同一套缩放比。

而这里的新细节来自所有新加入的 `q`：

```math
q = M_{\text{old}}, M_{\text{old}}+1, ..., M_{\text{new}}-1.
```

它们的尺度、位置、倾斜率都由不同的整数算术决定，不是同一个模板按固定比例复制出来的。

### 4.3 各个峰的局部斜率本身就不统一

在解析最优点

```math
k^* = m/M,\quad \gcd(m,M)=1
```

附近，令 `a` 是 `m` 关于模 `M` 的逆元，即

```math
am \equiv 1 \pmod M,
```

则局部满足

```math
s_M(k^*+\varepsilon)
= \min\Bigl(\frac{1}{M}+a\varepsilon,\ \frac{1}{M}-(M-a)\varepsilon\Bigr)
```

在足够小的邻域内成立。

这说明局部峰一般是**偏斜帐篷**，不是对称三角形。不同分支的 `a` 不同，所以各个峰连局部形状都不完全一样。

例如 `M=9, m=2` 时：

- `a=5`
- 左斜率 `= +5`
- 右斜率 `= -4`

所以它不是“放大后还是同一个对称小峰”的那种自相似。

## 6. 最稳妥的结论表述

如果要写成一句严格而又贴近直觉的话，我建议用下面这种说法：

> `s_min` 景观随 `M` 增大呈现出明显的层级细化结构：大 `M` 曲线是小 `M` 曲线的下包络加细版本，原有粗轮廓被保留，而更高阶差值约束在其下方引入更细的子结构。  
> 因此它具有明显的“分形感”或“准自相似”视觉特征，但从严格数学意义上看，它并不是由单一缩放律生成的精确分形。

如果要更短一点，可以压成：

> 不是严格分形，但确实是“算术嵌套式的层级细化”。

## 7. 对图 2 的直接解释

回到你这张图：

- `M=4` 给出最粗的全局轮廓；
- `M=9` 在这个粗轮廓下面进一步切出更多峰谷；
- `M=15` 再继续细化；
- 所以肉眼会觉得“大 `M` 像是小 `M` 的分形展开”。

这个感觉不是错觉，但更准确的数学语言应当是：

**嵌套下包络 + 算术细化**，而不是严格自相似分形。
