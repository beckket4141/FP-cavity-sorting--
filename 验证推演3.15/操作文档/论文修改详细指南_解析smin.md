# 解析 $s_{\min}$ 新发现：论文修改详细指南

> 本文档评估连续满载 $s_{\min}$ 解析规律对论文 ch05 各节的影响，给出逐节修改方案和优先级。
> **数值验证已全部完成**（见第7节），所有核心命题均已确认成立。

---

## 0. 核心发现概要（供快速回顾）

对连续模式集 $S_N = \{1,2,\dots,N\}$：

1. **解析最优**：$s_{\min}^{\max} = 1/N$，在 $k^* = m/N$（$\gcd(m,N)=1$）时精确达到
2. **几何映射**：$(L/R)^* = \sin^2(\pi m/N)$
3. **容量判据**：$N$ 模连续满载可行 $\Leftrightarrow$ $1/N \ge \tau_0/\mathcal{F}$，即 $N \le \lfloor\mathcal{F}/\tau_0\rfloor$
4. **平台裕度**：解析最优点附近存在满足 $s_{\min} \ge \delta$ 的连续区间，宽度由 $1/N - \delta$ 决定
5. **实验验证**：$k \approx 0.2212$ 非常接近 $2/9 = 0.2222$，$(L/R)^* = \sin^2(2\pi/9) \approx 0.4132$ 与实验 $0.410$ 吻合

### 1.2 §5.2 无量纲分辨率判据 τ

**现有内容**（L110-L265）：τ 定义、对比度公式、多模累积惩罚、容量上界 $M_{\max}$、速查表、QKD 接口。

**影响**：**最大**。τ 的角色需要强化，$M_{\max}$ 需要从"上界"升级为"精确可达容量"。

#### 修改 1.2a：§5.2.4（L207-L227）容量-质量权衡段落——核心重写

**现有问题**：
- L220-L225 说 $M_{\max} = \lfloor\mathcal{F}/\tau_0\rfloor$ 是"等间距排布假设下的上界"
- L227 说"是否取等取决于几何因子 $k$ 的具体取值与搜索范围"
- 但新发现告诉我们：**对连续满载，$M_{\max}$ 不只是上界，而是精确可达的**

**修改方案**：

在 L224 公式之后，**替换** L225-L227 的段落，改为分两个层次讨论：

**第一层（新增，约150字）**：连续满载的解析可达性
```
对于连续低阶模式集 S_N = {1,...,N}，该上界是精确可达的。
具体地，当归一化几何因子取 k* = m/N（gcd(m,N)=1）时，
N 个模式在圆周上等间距分布，s_min = 1/N。
此时 τ_eff = F·s_min = F/N，
分辨率判据 τ_eff ≥ τ_0 等价于 N ≤ F/τ_0 = M_max。
因此，连续满载的容量上限不仅是一个组合上界，
而且在解析最优几何参数处精确实现。
```

**第二层（保留，微调）**：一般模式集合的约束
```
然而，对于一般（非连续）模式集合，
或当 k 偏离解析最优点时，
实际可分辨模式数受几何约束可能低于 M_max。
§5.3 的 MIS 算法正是解决这一一般化问题的工具。
```

#### 修改 1.2b：§5.2.4 新增"存在性判据"段落

**位置**：紧接上述修改之后（L227之后）

**内容**：
```
由此可得一个简洁的存在性判据：
N 模连续满载在给定 F 和 τ_0 下可行，当且仅当 1/N ≥ τ_0/F。
以本文参数为例：F=29.8, τ_0=3, δ=0.100671。
对 N=9：1/9=0.111111 > δ，满载可行。
对 N=10：1/10=0.100000 < δ，满载不可行——
即使在解析最优点 k=m/10 处，s_min=0.1 仍低于阈值。
因此，在当前精细度和质量要求下，
9 模恰好是连续满载的容量极限。
```
