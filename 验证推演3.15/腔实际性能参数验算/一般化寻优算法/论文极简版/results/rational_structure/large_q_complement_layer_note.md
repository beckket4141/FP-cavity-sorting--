# 大分母补集层判据：把“最多到第二层”压成一条更短的精确规则

这份笔记是在 `q>D_max` 的投影壳层筛分基础上，再往前压一步。
目标是把当前例子里的结论

> “所有大分母 admissible 分支都只会在第一层或第二层命中差分集”

写成一条更短的、直接依赖差分补集的精确判据。

---

## 1. 记号

当前仍记差分集合为 `D(S)`，其最大值为

`D_max = max D(S)`.

并定义低区间补集

`C(S) = {1,2,...,D_max} \ D(S)`.

对当前 12 模例子，

`D_max=45`,

且

`C(S) = {1,20,29,32,35,37,38,41,43,44}`.

对每个大分母

`q>D_max`

和 admissible 分支 `m`，定义第 `r` 层在低区间 `[1,D_max]` 上的投影

`Pi_q(m,r)`.

它就是逆元壳层 `{± r m^{-1}} mod q` 中，真正落回 `[1,D_max]` 的那些点。

---

## 2. 命题 P3：大分母下的补集层判据

设 `D_max < q <= 2 D_max`。

则对任意 admissible 分支 `m`，有：

1. `rho_q(m;S) >= 2`
   当且仅当
   `Pi_q(m,1) subseteq C(S)`.

2. `rho_q(m;S) >= 3`
   当且仅当
   `Pi_q(m,1) subseteq C(S)` 且 `Pi_q(m,2) subseteq C(S)`.

### 证明

由前一个投影壳层命题，

`rho_q(m;S)`

正是第一层使

`Pi_q(m,r) ∩ D(S) != emptyset`

成立的层号。

因此：

- `rho_q(m;S) >= 2`
  等价于第一层还没有命中 `D(S)`，
  即 `Pi_q(m,1) ∩ D(S) = emptyset`。
  因为 `Pi_q(m,1) subseteq [1,D_max]`，
  这又等价于 `Pi_q(m,1) subseteq C(S)`。

- 同理，
  `rho_q(m;S) >= 3`
  等价于前两层都还没有命中 `D(S)`，
  即
  `Pi_q(m,1) ∩ D(S) = emptyset`
  且
  `Pi_q(m,2) ∩ D(S) = emptyset`，
  也就等价于
  `Pi_q(m,1) subseteq C(S)`
  且
  `Pi_q(m,2) subseteq C(S)`。

证毕。

### 解释

这条命题的价值在于，它把大分母分支的判断进一步收缩成了：

- 看第一层投影是不是已经掉进差分补集；
- 若是，再看第二层投影是不是也还在补集里。

也就是说，当前问题的大分母尾部已经不再是“复杂模结构”，而更像是一个**低区间补集上的层筛分问题**。

---

## 3. 对当前例子的精确验证

对当前例子的全部大分母范围

`46 <= q <= 90`

逐 branch 精确核对后，得到：

- `rho>=2` 与“第一层投影完全落在补集 `C(S)`”完全一致；
- `rho>=3` 与“第一、第二层投影都完全落在补集 `C(S)`”完全一致；
- 但当前例子里**没有任何 admissible 分支通过第二层补集检验**。

换句话说：

> 所有大分母 admissible 分支，要么第一层就撞上 `D(S)`，
> 要么第一层落在补集里，但第二层必然撞上 `D(S)`。

因此当前例子里必有

`rho_q(m;S) <= 2`

对所有

`46 <= q <= 90`

的 admissible 分支成立。

---

## 4. 为什么这条结论比单纯列举更值钱

如果只是列举，我们只能说：

- `73,76,78,82,...,90` 这些分母的最佳层号是 `2`

但现在的说法更短，也更像一个可复用规则：

1. 对大分母，先看 `Pi_q(m,1)` 是否已落在差分补集；
2. 若第一层已撞到 `D(S)`，该分支立即结束；
3. 若第一层仍在补集，再看 `Pi_q(m,2)`；
4. 对当前例子，第二层补集空缺根本没有出现，因此所有大分母都止步于第二层。

这条规则依然没有把问题夸大成“一般闭式最优分母”，
但它已经比“我把大分母都枚举了一遍”明显更强。

---

## 5. 对 `q=29` 最优性的进一步支撑

当前已知最优值为

`s_min^* = 1/29`.

而大分母区间现在已经被补集层判据压到：

- 所有 admissible 分支都满足 `rho<=2`
- 且第一批 `rho=2` 的分母只从 `q=73` 才开始

所以所有大分母候选都满足

`s_min <= 2/73 < 1/29`.

因此：

> 对当前 12 模例子，`q=29` 的最优性不仅来自精确 `(q,m)` 搜索，
> 还得到了一个更短的大分母补集层剪枝支撑：
> 大分母尾部根本没有第三层幸存分支，自然不可能反超 `1/29`。

---

## 6. 当前最值得保留的一句话

> 在 `D_max < q <= 2D_max` 的大分母区间里，固定分支 `m` 的评分可以用低区间补集 `C(S)` 做层筛分：`rho_q(m)>=2` 当且仅当第一层投影 `Pi_q(m,1)` 完全落在 `C(S)` 中，而 `rho_q(m)>=3` 当且仅当第一、第二层投影都完全落在 `C(S)` 中。对当前 12 模例子，这个第二层补集条件从未出现，因此所有大分母 admissible 分支都满足 `rho<=2`，从而不可能打过 `q=29` 的最优值。`
