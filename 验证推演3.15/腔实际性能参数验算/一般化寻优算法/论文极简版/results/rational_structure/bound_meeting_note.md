# 分层上界与复合下界“碰头”的判定

本文档研究：什么时候分层上界与复合下界会在同一个层号 `r` 上碰头，
从而把

`rho_q^*(I;S)`

用纯计数直接钉死。

---

## 1. 两个辅助量

延续前文记号。对固定分母 `q` 和层号 `r`，定义：

### 1.1 分支坏覆盖量

`C_q(r) = sum_{g|q, g<q} nu_{q,g}(S) lambda_q(g) beta_{q,g}(r).`

它是坏分支并集大小的一个统一上界。
如果

`mu_q(I) > C_q(r),`

则说明窗口中允许分支的总数，比“所有差分残基在第 `r` 壳层以内可能制造的坏分支总数上界”还多，
因此一定能找到某个好分支满足

`rho_q(m;S) >= r.`

### 1.2 分层裕量

对每个 `gcd` 层定义

`sigma_{q,g}(r) = phi(q/g) - beta_{q,g}(r) - nu_{q,g}(S).`

它表示：在要求“所有残基都避开第 `r` 壳层以内低壳禁区”时，
第 `g` 层还剩多少可用空位。

- 若 `sigma_{q,g}(r) >= 0`，则该层从计数上还未被挤爆；
- 若 `sigma_{q,g}(r) < 0`，则该层已经被挤爆，因此不可能再有分支满足 `rho_q(m;S) >= r`。

---

## 2. 一步碰头定理

### 定理 M（一步碰头）

若存在整数 `r>=0` 使得

1. `mu_q(I) > C_q(r)`,
2. 存在某个真因子层 `g* | q, g* < q` 使得 `sigma_{q,g*}(r+1) < 0`,

则有

`rho_q^*(I;S) = r.`

### 证明

由条件 1 和前述复合分母下界命题，存在某个允许分支 `m in M_q(I)` 使得

`rho_q(m;S) >= r`,

故

`rho_q^*(I;S) >= r.`

另一方面，条件 2 表示在第 `g*` 层上，
如果要求所有残基都避开第 `r+1` 壳层以内低壳禁区，则该层所需位置数已经超过其可用位置数。
因此任何分支都不可能满足

`rho_q(m;S) >= r+1`,

从而

`rho_q^*(I;S) <= r.`

两边合并即得

`rho_q^*(I;S) = r`.

证毕。

### 解释

这个定理把“碰头”拆成两件非常直观的事：

- 下界侧：窗口内可用分支还有盈余，坏分支不够把它们全部盖掉；
- 上界侧：某个 `gcd` 壳层已经先被挤爆，下一层号不可能再实现。

一旦这两件事同时发生在 `r` 与 `r+1` 的交界处，
`rho_q^*` 就被纯计数直接钉死为 `r`。

---

## 3. 两个直接推论

### 推论 M1：`rho_q^*=0` 的判定

若

- `0 in R_q(S)`，
- `mu_q(I) > 0`,

则

`rho_q^*(I;S)=0.`

也就是说，只要某个差分被 `q` 整除，而且窗口内确实存在允许分支，
那么这个分母必然对应碰撞。

### 推论 M2：`rho_q^*=1` 的简洁判定

若

- `0 notin R_q(S)`，
- `mu_q(I) > 0`，
- 存在某个 `g` 使得 `sigma_{q,g}(2) < 0`,

则

`rho_q^*(I;S)=1.`

### 证明

当 `r=1` 时，

`beta_{q,g}(1)=0`

对所有层都成立，因此

`C_q(1)=0.`

只要 `mu_q(I)>0`，就自动有

`mu_q(I) > C_q(1)`.

再结合一步碰头定理和 `sigma_{q,g}(2)<0`，立即得到

`rho_q^*(I;S)=1`.

证毕。

### 解释

这个推论很有用，因为它说明：

只要窗口里至少有一条可用分支，且某个 `gcd` 层在第二层号就已经被挤爆，
那么该分母的最佳层号就不需要再搜，必定正好等于 `1`。

## 4. 素数分母情形的进一步化简

若 `q` 为素数，则唯一的非零层只有 `g=1`，于是

- `nu_{q,1}(S) = nu_q(S)`
- `lambda_q(1) = 1`
- `beta_{q,1}(r) = 2(r-1)`
- `sigma_{q,1}(r) = (q-1) - 2(r-1) - nu_q(S)`

因此一步碰头定理退化为：

### 推论 M3：素数分母的一步碰头判据

若 `q` 为素数，且存在整数 `r>=1` 满足

1. `mu_q(I) > 2(r-1) nu_q(S)`,
2. `nu_q(S) > (q-1) - 2r`,

则

`rho_q^*(I;S)=r`.

这意味着：对素数分母，碰头条件只由两个量控制：

- `mu_q(I)`：窗口里到底有多少条允许分支；
- `nu_q(S)`：差分残基到底有多拥挤。

## 5. 当前集合中的两个典型例子

当前集合为

`S=[1,4,6,10,15,18,22,27,31,37,40,46]`,

窗口为

`I=[0.2,0.3]`.

### 5.1 `q=29`

- `29` 为素数
- `mu_29(I)=3`
- `nu_29(S)=27`

对 `r=1`，

- 下界侧：`3 > 0`
- 上界侧：`27 > 28-2 = 26`

故由推论 M3 可直接得到

`rho_29^*(I;S)=1`,

即

`s_29^*(I;S)=1/29`.

### 5.2 `q=32`

在 `q=32` 时，

- 允许分支为 `m=7,9`，故 `mu_32(I)=2`
- 分层分布为 `1:15;2:8;4:3;8:2;16:1`

对 `r=1`，

- 下界侧依然自动成立，因为 `C_32(1)=0`
- 上界侧在 `g=1` 层已经失败：
  `sigma_{32,1}(2)=phi(32)-beta_{32,1}(2)-nu_{32,1}=16-2-15=-1`

故一步碰头定理直接给出

`rho_32^*(I;S)=1`.

这解释了为什么 `q=32` 也能被纯计数直接钉死。

---

## 6. 为什么 `q=35` 暂时钉不死

对 `q=35`，

- 复合下界只能保证 `rho_35^* >= 1`
- 分层上界只给出 `rho_35^* <= 2`

也就是说，窗口分支的盈余只够把结果顶到 `1`，
但没有哪个 `gcd` 层会在第二层号就立刻被挤爆。

因此 `q=35` 目前落在

`1 <= rho_35^*(I;S) <= 2`

这个窄区间里，尚未发生“碰头”。
数值精确结果告诉我们它实际上等于 `1`，
但这一步还需要比当前计数上界更细的结构信息。

---

## 7. 当前最稳妥的一句话总结

> 所谓“分层上界与复合下界碰头”，本质上就是：在层号 `r` 处，窗口内可用分支的总数仍然超过所有低壳坏分支的覆盖上界，而在层号 `r+1` 处，某个 `gcd` 壳层已经先被挤爆。前者把 `rho_q^*` 从下方托到至少 `r`，后者把它从上方压到至多 `r`，两者合并即得 `rho_q^*=r`。因此，最优层号的精确值在很多情形下可以由“分支盈余”和“层饱和亏空”这两个纯计数量直接决定。
