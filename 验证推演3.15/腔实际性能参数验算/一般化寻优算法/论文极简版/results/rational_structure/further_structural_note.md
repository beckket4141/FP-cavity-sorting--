# 关于 `q` 与 `m` 的进一步结构说明

本文档回答两个更往前一步的问题：

1. 能否把最优分母 `q` 的规律写得更数学化？
2. `m` 影响结果的方式，能否写成明确的数学形式？

这里仍然坚持一条原则：只写当前已经能够较稳说明的内容，不把尚未完成的部分伪装成闭式定理。

---

## 1. 目前最精确的全局表述

设

- 模式集合为 `S`
- 差分集合为 `D=D(S)`
- 窗口为 `I=[a,b]`
- 分母上界为
  `Q_I(S)=max(den(a), den(b), 2 max D)`

则当前问题已经可以**完全等价**地写成：

`max_{k in I} s_min(k;S) = max_{1<=q<=Q_I(S)} max_{m : gcd(m,q)=1, a<=m/q<=b} (1/q) rho_q(m;S)`

其中

`rho_q(m;S)=min_{d in D} dist_q(md,0)`,

`dist_q(r,0)=min(r mod q, q-r mod q)`.

这已经不是“数值暗示”，而是一个严格的有限精确搜索形式。

因此，当前最好的说法不是“已经有简单闭式 `q=f(S)`”，而是：

> 一般有限模式集合的连续优化问题已经严格降为一个有限 `(q,m)` 集合上的精确极值问题。

---

## 2. `q` 的数学角色：它控制“允许的距离分层”

对固定 `q`，圆周上的离散距离不是连续的，而是分层的：

`1/q, 2/q, ..., floor(q/2)/q`.

于是 `rho_q(m)` 可以理解为：

> 差分集合 `D` 经乘法缩放 `d -> md mod q` 后，第一次撞到离原点最近距离层的层号。

也就是说，`q` 决定了可用的“距离刻度”；  
`m` 决定了差分集合在这些距离层上的落位。

所以目前最自然的结构语言不是“闭式 `q=f(S)`”，而是：

- `q` 决定距离刻度；
- `m` 决定差分集合在这些刻度上的投影方式；
- 最终分数是 `rho_q(m)/q`。

---

## 3. `m` 如何影响结果：一个完全精确的数学形式

对固定 `q`，定义第 `r` 层对称壳层

`Sigma_q(r) = {r, q-r}`,  `1 <= r <= floor(q/2)`.

再定义缩放后的差分残基集合

`D_q(m) = {(md) mod q : d in D}`.

则有一个非常干净的等价表达：

`rho_q(m) = min { r >= 1 : D_q(m) ∩ Sigma_q(r) != empty }`.

也就是说：

> `rho_q(m)` 恰好等于缩放后的差分集合第一次碰到哪一层距离壳层。

从而

`rho_q(m) >= r`

当且仅当

`D_q(m)` 同时避开

`Sigma_q(1), Sigma_q(2), ..., Sigma_q(r-1)`.

这给出了 `m` 影响结果的**精确数学形式**：

- `m` 不是抽象“微调参数”；
- `m` 的作用就是把差分集合推到模 `q` 的不同距离壳层上；
- 优的 `m`，就是那些能让 `D_q(m)` 尽量晚碰到靠近 0 的壳层的 `m`。

---

## 4. 关于 `m` 的一个更形式化的“半解析”写法

对固定 `q` 与整数 `r>=1`，定义禁区集合

`B_{q,r}(S) = { m in U(q) : exists d in D, dist_q(md,0) < r }`,

其中 `U(q)` 是模 `q` 的单位群。

那么

`rho_q(m) >= r  <=>  m notin B_{q,r}(S)`.

于是固定 `q` 时的最优层号可以写成

`rho_q^*(I;S) = max { r : exists m in M_q(I) with m notin B_{q,r}(S) }`,

其中

`M_q(I) = { m : gcd(m,q)=1, a<=m/q<=b }`

是窗口内允许的分支集合。

于是最优分母问题变成：

`q^* in argmax_q rho_q^*(I;S) / q`.

这个写法虽然还不是闭式解，但已经非常接近一个纯离散的数论-组合问题了。

---

## 5. 为什么“简单闭式 `q=f(S)`”目前看起来不太像普适事实

从上面的精确形式可以看出，`q` 的优劣并不只由一个标量控制，而是取决于：

- 差分集合 `D` 在模 `q` 下的全部残基分布
- 这些残基在壳层 `Sigma_q(r)` 上的命中顺序
- 允许窗口 `M_q(I)` 是否包含“好分支” `m`

因此，对一般集合而言，`q` 的优劣依赖的是一整套模结构，而不只是：

- 模式数 `M`
- 最大阶数 `max S`
- 差分个数 `|D|`
- 或某个单独的 gcd/lcm

这也是为什么当前更自然的猜测是：

> 普适的“一行闭式 `q=f(S)`”未必存在；
> 但存在一个完全精确、且候选数有限的 `(q,m)` 离散搜索框架。

---

## 6. 当前集合里的一个精确示例：为什么 `q=29` 特别好

对当前集合

`S=[1,4,6,10,15,18,22,27,31,37,40,46]`

有

`D mod 29`

几乎覆盖了全部非零残基，只缺极少数点。对应到距离壳层语言上，这意味着：

- 缩放后的差分集合 `D_29(m)` 很难同时避开靠近 0 的最内层；
- 但它又能恰好避开碰撞层 `0`；
- 结果就是在当前窗口内，`q=29` 给出了最优的第一层可分辨间距
  `s_min = 1/29`。

而在 `m=6,7,8` 这三个分支上，壳层命中顺序恰好等价，因此都达到 `1/29`。

这说明：

- `q=29` 的特殊性来自当前差分集合的模结构；
- `m` 的三重并列最优来自允许窗口里恰好有三条分支把差分集合送到了等价的壳层结构。

## 7. 可以继续推进的方向

如果后面还要再前进一步，最值得研究的不是“立刻闭式求 `q`”，而是这两个方向：

### 方向 A：寻找 `q` 的充分条件

例如尝试证明：

- 若 `D mod q` 避开某些低层壳层，则必有 `s_min >= r/q`
- 若 `D mod q` 足够稠密，则必有 `s_min <= r/q`

这会给出 `q` 的上下界，而不必一步写出闭式。

### 方向 B：研究 `m` 的轨道分类

对固定 `q`，把全部允许的 `m` 按照 `D_q(m)` 的壳层命中结构分类。  
若能证明许多 `m` 实际上落在少数几个等价类里，那么 `(q,m)` 搜索还能继续压缩。

---

## 8. 当前最稳妥的研究性结论

如果现在要把这条线写成一句研究性摘要，最稳妥的版本是：

> 对一般有限模式集合，最小间距优化问题不仅可以精确有理化，而且已经可以严格改写为一个有限 `(q,m)` 集合上的离散极值问题。其中，分母 `q` 控制可用的离散距离刻度，分支 `m` 则决定差分集合在模 `q` 意义下首先命中哪一层距离壳层。当前尚未得到普适的一步闭式 `q=f(S)`，但 `q` 与 `m` 的作用方式都已能用明确的数论-组合结构来刻画。

这句话比“已经有通用闭式解”弱，但比“只是数值现象”强得多。
