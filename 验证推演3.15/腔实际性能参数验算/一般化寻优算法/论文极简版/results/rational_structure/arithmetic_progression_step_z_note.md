# 等差模式集的解析结构：连续满载解析解的干净推广

这份笔记把原先工作态的“步长 `z` 推广”整理成更适合论文吸收的版本。
文件名中保留 `step_z` 只是历史遗留；正文与后续写作中建议统一改用 `\Delta_\mathrm{ord}`。

为了避免与 LG 模式中的传播坐标 `z` 混淆，下面统一把等差模式集的公共阶数步长记为

`Delta_ord`.

也就是说，我们研究的对象不是一般任意离散集合，而是下面这一类特殊集合：

`S_{N_start,Delta_ord,M} = {N_start, N_start + Delta_ord, ..., N_start + (M-1)Delta_ord}`.

这类集合介于两端之间：

- 比连续满载集 `S_M={1,2,...,M}` 更一般；
- 但远比任意离散集合特殊，因此仍然保留闭式结构。

这也是这条结果最值得保留的定位：

> 它不是“一般离散集合也有闭式解”，而是“等差模式集仍然是闭式可解的一类 special family”。

---

## 1. 结论先写在前面

对等差模式集

`S_{N_start,Delta_ord,M} = {N_start + t Delta_ord : t=0,1,...,M-1}`,

在不额外施加狭窄工程窗口、只要求

`0 < k < 1/2`

时，有：

1. 最优最小间距仍然是
   `s_min^* = 1/M`
2. 解析最优条件从连续满载情形的
   `k = m/M`
   变成
   `Delta_ord k ≡ m/M (mod 1)`, `gcd(m,M)=1`
3. 因而完整解析最优分支族为
   `k^* = (n + m/M)/Delta_ord`,
   其中 `n` 为整数，且 `0 < k^* < 1/2`
4. 最简单的一组代表分支是
   `k^* = m/(M Delta_ord)`.

所以，从圆周最小间距的角度看：

> 等差模式集与连续满载集完全同构，只是把“有效步长”从 `k` 换成了 `u = Delta_ord k (mod 1)`。

---

## 2. 定义与约化

正文里已有归一化圆周模型

`pos(N) = ((N-1)k) mod 1`.

对等差模式集中的第 `t` 个模式

`N_t = N_start + t Delta_ord`,

其圆周位置为

`pos_t = ((N_start-1) + t Delta_ord)k mod 1`.

把它写成

`pos_t = c + t u mod 1`,

其中

- `c = ((N_start-1)k) mod 1`
- `u = (Delta_ord k) mod 1`

于是立刻得到第一个关键观察：

### 观察 O1：`N_start` 只产生整体平移

`c` 只是整组点在圆周上的共同平移，不改变任意两点间距。

因此：

> 等差模式集的最小间距问题与起始阶数 `N_start` 无关；
> 真正决定结构的只有模式数 `M` 与有效步长 `u = Delta_ord k (mod 1)`。

这一步非常关键，因为它说明：

- 起点不影响最优值；
- 问题已经被压缩成“`M` 个点以固定有效步长 `u` 在圆周上前进”的模型。

---

## 3. 命题 P1：与连续满载问题的严格同构

对任意等差模式集 `S_{N_start,Delta_ord,M}`，有

`s_min(k; S_{N_start,Delta_ord,M}) = min_{1<=d<=M-1} || d Delta_ord k ||`.

更强地说，若记

`u = (Delta_ord k) mod 1`,

则

`s_min(k; S_{N_start,Delta_ord,M}) = s_min(u; S_M)`,

其中 `S_M={1,2,...,M}` 为连续满载集。

### 证明

当前集合的差分集合为

`D(S_{N_start,Delta_ord,M}) = {Delta_ord, 2 Delta_ord, ..., (M-1) Delta_ord}`.

由正文已有的差分集合约化公式，

`s_min(k;S) = min_{d in D(S)} || d k ||`,

立刻得到

`s_min(k; S_{N_start,Delta_ord,M}) = min_{1<=d<=M-1} || d Delta_ord k ||`.

再令

`u = (Delta_ord k) mod 1`,

便得

`s_min(k; S_{N_start,Delta_ord,M}) = min_{1<=d<=M-1} || d u || = s_min(u; S_M)`.

证毕。

### 解释

这条命题是整条推广的核心。

它的意义不是“好像很像连续满载”，而是：

> 等差模式集在圆周最小间距问题上，与连续满载集严格同构。

所以后面所有闭式结论，其实都可以直接从连续满载解搬过来。

---

## 4. 定理 T1：无额外窗口约束时的解析最优解

对任意等差模式集 `S_{N_start,Delta_ord,M}`，若只要求

`0 < k < 1/2`,

则

`s_min^*(S_{N_start,Delta_ord,M}) = 1/M`.

并且取等当且仅当

`Delta_ord k ≡ m/M (mod 1), \qquad gcd(m,M)=1`.

### 证明

由命题 P1，

`s_min(k; S_{N_start,Delta_ord,M}) = s_min(u; S_M)`,

其中 `u = Delta_ord k (mod 1)`.

而连续满载集 `S_M` 的闭式解已在正文中给出：

- `M` 个点在单位圆周上的最小间距不可能超过 `1/M`
- 且当且仅当这 `M` 个点等间隔排布时取等
- 等间隔排布当且仅当
  `u = m/M`, `gcd(m,M)=1`

因此当前等差模式集的最优值仍然是

`1/M`,

而取等条件恰为

`Delta_ord k ≡ m/M (mod 1)`.

证毕。

### 解释

这条定理说明：

- 连续满载解析解之所以成立，真正原因不是“恰好是从 1 开始的连续整数”
- 而是“圆周上等效地形成了一个固定步长的长度为 `M` 的算术轨道”

等差模式集恰好保留了这一结构，因此闭式解仍然存在。

---

## 5. 解析最优分支的完整显式形式

由

`Delta_ord k ≡ m/M (mod 1)`

可得全部解析最优分支满足

`k^* = (n + m/M)/Delta_ord`,

其中

- `n` 为整数；
- `gcd(m,M)=1`；
- `0 < k^* < 1/2`.

因此对应几何比为

`(L/R)^* = sin^2 [ pi (n + m/M)/Delta_ord ]`.

### 最简单代表分支

若只想写最简的一组解析分支，可取 `n=0`：

`k^* = m/(M Delta_ord), \qquad gcd(m,M)=1`.

这是最短、最容易写进工作笔记的一族。

### 但要注意：它不是完整最优族

完整最优族一般不止 `n=0` 这一组。

例如 `M=5, Delta_ord=3` 时，

- 最简单子族包括
  `1/15, 2/15, 1/5, 4/15`
- 但完整最优族还包括
  `2/5, 7/15`

所以如果要把定理写完整，必须写成

`k^* = (n + m/M)/Delta_ord`

而不能只写 `k=m/(M Delta_ord)`。

---

## 6. 容量边界不变

因为无额外窗口约束时仍有

`s_min^* = 1/M`,

所以正文中的容量边界不变：

`tau_min = F s_min >= tau_0`

仍然导出

`F/M >= tau_0`,

即

`M <= floor(F / tau_0)`.

因此从纯频谱折返几何看：

> 等差模式集与连续满载集拥有相同的理想容量边界。

---

## 7. 加入工程窗口后的边界

上面的闭式解针对的是“无额外窄窗口”的情形。

若再加入工程窗口

`k in I=[a,b] subset (0,1/2)`,

则要分两种情况：

### 情况 A：窗口内存在解析最优分支

若存在整数 `n` 与互质 `m` 使

`a <= (n + m/M)/Delta_ord <= b`,

则窗口内最优值仍为

`s_min^* = 1/M`.

### 情况 B：窗口内不存在解析最优分支

则无约束最优值 `1/M` 仍然正确，但在当前窗口内不可达。

这时受限问题不再由一步闭式结束，而需要在窗口内继续做有限有理搜索。

这句边界要说清楚，因为它决定了这条结果在正文里的强度：

> “等差模式集有解析解”对无约束问题成立；
> 但若额外强加狭窄工程窗口，仍需检查解析最优分支是否落窗。

---

## 8. 物理实现上的区别

这条结果只说明：

- 从归一化圆周最小间距的角度看，等差模式集与连续满载集等价

它不自动说明：

- 实际实验性能也会完全一样

因为当 `Delta_ord` 增大时，最高阶模式

`N_start + (M-1) Delta_ord`

也会迅速升高，而更高阶模式常常对应：

- 更差的峰值透射率
- 更强的模式匹配敏感性
- 更高的探测端不均匀性

所以最稳的写法是：

- **频谱折返几何上**，等差模式集仍有闭式解；
- **工程实现上**，高阶模式引入的额外损耗仍需单独评估。

---

## 9. 这条结果在论文中的正确定位

我建议把它定位成：

> 连续满载解析结构的一个干净推广

而不是：

> 一般离散集合的进一步统一闭式理论

因为它本质上仍是一个 highly structured family：

- 差分集合只是
  `Delta_ord * {1,2,...,M-1}`
- 所以解析解能保留

一旦离开这类结构，回到任意离散集合，问题仍然需要有限 `(q,m)` 精确搜索。

## 10. 数值核对如何支撑这条结论

配套脚本 [verify_arithmetic_progression_closed_form.py](/D:/自制软件/1.thesis/My_nju_thesis-master/thesis/验证推演3.15/腔实际性能参数验算/一般化寻优算法/论文极简版/verify_arithmetic_progression_closed_form.py) 现在验证了三件事：

- 对测试到的全部等差模式集，精确搜索都给出 `s_min^*=1/M`
- 对测试到的全部样例，完整最优族都与
  `k^*=(n+m/M)/Delta_ord` 完全一致
- 对重复的 `(Delta_ord,M)` 组合，改变 `N_start` 不会改变最优值与最优分支族

这里第三点很重要，因为它直接对应上面的观察 O1，而不是只在文字上说“`N_start` 只是平移”。

同时，数值结果也再次提醒了一个写作上必须说清楚的点：

- `k=m/(M Delta_ord)` 只是最简单代表子族
- 当 `Delta_ord` 足够大时，完整最优族一般严格大于这组最小子族

因此正文若要写成命题，必须写完整族
`k^*=(n+m/M)/Delta_ord`，
而不能只保留 `n=0` 的一支。

## 11. 当前最值得记住的一句话

> 对任意等差模式集 `S_{N_start,Delta_ord,M}={N_start, N_start+Delta_ord, ..., N_start+(M-1)Delta_ord}`，圆周最小间距问题可严格约化为连续满载集 `S_M={1,2,...,M}` 的同一个问题，只需把有效步长替换为 `u = Delta_ord k (mod 1)`。因此，在无额外窗口约束时，其解析最优值仍为 `s_min^*=1/M`，且取等当且仅当 `Delta_ord k ≡ m/M (mod 1)`（`gcd(m,M)=1`）。
