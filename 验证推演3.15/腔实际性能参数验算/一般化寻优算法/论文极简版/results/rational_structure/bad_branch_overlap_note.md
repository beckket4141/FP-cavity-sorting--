# 固定 `q` 时的坏分支重叠与精确覆盖

本文档研究一个比并集上界更精细的问题：

> 对固定分母 `q` 与层号 `r`，所有“低壳坏事件”在允许分支集合 `M_q(I)` 上到底怎样重叠？

这一步的意义在于：如果能把坏分支并集算精确，就不再需要粗糙的并集上界，
从而有机会把 `q=35` 这类“只差半步”的分母也直接钉死。

---

## 1. 坏分支集合

对固定 `q`、固定半径 `r>=1`、固定非零差分残基 `u in R_q^x(S)`，定义

`B_q(u,r) = { m in M_q(I) : dist_q(mu,0) < r }.`

它表示：对于残基 `u` 来说，哪些允许分支 `m` 会让它落入第 `r` 壳层以内，
从而成为“坏分支”。

---

## 2. 精确坏并集

定义精确坏并集

`U_q(r) = | union_{u in R_q^x(S)} B_q(u,r) |.`

它不是上界，而是窗口内真实被“至少一个差分残基”判坏的分支总数。

### 命题 O1

有

`rho_q^*(I;S) >= r  <=>  U_q(r) < mu_q(I).`

### 证明

根据定义，

`rho_q(m;S) >= r`

当且仅当对所有 `u in R_q^x(S)` 都有

`dist_q(mu,0) >= r`,

也就是

`m notin B_q(u,r)` for all `u`.

这等价于

`m notin union_u B_q(u,r)`.

因此存在某个好分支 `m in M_q(I)` 使得 `rho_q(m;S) >= r`
当且仅当坏分支并集没有覆盖全部允许分支，即

`U_q(r) < mu_q(I)`.

证毕。

### 推论 O2

有

`rho_q^*(I;S) = r`

当且仅当

`U_q(r) < mu_q(I)` 且 `U_q(r+1) = mu_q(I)`.

这给出了一个完全精确的判定：

- 在半径 `r` 处，仍有幸存分支；
- 在半径 `r+1` 处，所有允许分支都被坏并集完全覆盖。

---

## 3. 坏分支模式分类

为了研究重叠结构，定义模式映射

`P_{q,r}(u) = B_q(u,r) subseteq M_q(I).`

于是不同残基 `u` 会被分成若干模式类：

`Gamma_{q,r}(P) = { u in R_q^x(S) : P_{q,r}(u) = P }.`

### 解释

这个分类的意义非常直接：

- 若很多残基给出同一个坏分支模式 `P`，说明它们高度重叠；
- 若只出现少数几个模式，且这些模式的并集已经覆盖全部 `M_q(I)`，
  那么即使原始残基很多，实际坏覆盖也可能很“稀薄而致命”。

因此，研究 `Gamma_{q,r}(P)` 比简单相加 `|B_q(u,r)|` 更接近真实几何结构。

---

## 4. `q=35` 的精确解释

对当前集合

`S=[1,4,6,10,15,18,22,27,31,37,40,46]`

在窗口

`I=[0.2,0.3]`

内，`q=35` 的允许分支只有

`M_35(I) = {8,9}`.

我们已经知道精确结果是

`rho_35^*(I;S)=1`.

下面说明如何仅用坏分支模式把它钉死。

### 4.1 半径 `r=1`

此时

`dist_q(mu,0) < 1`

不可能发生在非零残基上，因此

`B_35(u,1) = emptyset`

对所有 `u` 都成立。
故

`U_35(1)=0 < 2 = mu_35(I)`.

所以至少存在允许分支满足

`rho_35(m;S) >= 1`.

### 4.2 半径 `r=2`

此时只要满足

`mu equiv ±1 mod 35`

就会成为坏分支。
精确模式分类结果是：

- 残基 `13,22` 给出模式 `{8}`
- 残基 `4,31` 给出模式 `{9}`
- 其余非零残基给出模式 `emptyset`

因此坏分支模式的并集正好是

`{8} union {9} = {8,9} = M_35(I)`.

故

`U_35(2)=2 = mu_35(I)`.

由推论 O2 立刻得到

`rho_35^*(I;S)=1`.

### 解释

这说明 `q=35` 之所以没能在 earlier counting bounds 中碰头，
不是因为还存在某个隐藏的好分支 `m`，
也不是因为两个允许分支其实等价，
而是因为：

- `m=8` 被一对特定残基 `13,22` 精确击中；
- `m=9` 被另一对特定残基 `4,31` 精确击中；
- 两组坏模式虽然都很小，但并在一起刚好覆盖全部允许分支。

这是一种“稀薄但完全覆盖”的失败机制。

---

## 5. 这一步的意义

这一层分析说明：

1. 当前粗下界的松弛，确实主要来自并集估计太粗；
2. 对某些 `q`，只要把坏分支模式分出来，就能直接把 `rho_q^*` 精确钉死；
3. `q=35` 就是这种情形的典型例子。

因此，固定 `q` 时研究 `m` 的分类与坏分支模式，不只是辅助说明，
而是把“上下界差半步”推进到精确判定的直接工具。

---

## 6. 当前最稳妥的一句话总结

> 对固定分母 `q`，与其对所有坏分支集合 `B_q(u,r)` 做粗糙相加，不如先按坏分支模式 `P_{q,r}(u)` 分类，再研究这些模式在允许分支集合 `M_q(I)` 上的精确并集。这样可以把“下界为什么还差半步”还原成一个明确的覆盖问题。对当前例子中的 `q=35`，正是因为两类极小的坏模式 `{8}` 与 `{9}` 的并集已经覆盖全部允许分支，才导致 `rho_35^*=1` 被纯结构直接钉死。
