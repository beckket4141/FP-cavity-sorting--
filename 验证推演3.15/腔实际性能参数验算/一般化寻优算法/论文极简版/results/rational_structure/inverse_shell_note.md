# 逆元壳层判据：一条比“继续深挖一般理论”更短、也更能直接筛分母的命题

这份笔记只记录这次新推进里**已经能稳写成命题/推论**的部分。
目标不是再把问题往更深的一般数学结构里硬推，而是回答一个更直接的问题：

> 能不能从现有 `(q,m)` 精确搜索框架里，再抽出一条短、准、对设计者立刻有用的判据？

当前答案是：**可以，至少可以稳地抽出一条“逆元壳层判据”，它能精确回答什么时候某个分母 `q` 只能给出 `1/q`，以及什么时候立刻知道存在 `>=2/q` 的更好分支。**

---

## 1. 记号

设有限模式集合为 `S`，差分集合为 `D(S)`。

固定分母 `q`，定义非零差分残基集合

`R_q^x(S) = { d mod q : d in D(S), d mod q != 0 }`.

对互质分支 `m in U(q)`，仍记

`rho_q(m;S) = min_{d in D(S)} dist_q(md,0)`,

于是

`s_min(m/q;S) = rho_q(m;S) / q`.

再对任意 `r >= 1`，定义 `m` 的第 `r` 个逆元壳层

`Lambda_q(m,r) = { +r m^{-1}, -r m^{-1} } mod q`,

其中 `m^{-1}` 表示 `m` 在模 `q` 下的乘法逆元。

也就是说，`Lambda_q(m,1)` 就是最靠近原点的那一对逆元位置，
`Lambda_q(m,2)` 是第二层，依此类推。

---

## 2. 命题 P1：逆元壳层判据

对任意互质 `m` 与任意整数 `r >= 1`，有

`rho_q(m;S) >= r`

当且仅当

`R_q^x(S)` 与前 `r-1` 层逆元壳层全部不相交，即

`R_q^x(S) ∩ ( union_{t=1}^{r-1} Lambda_q(m,t) ) = emptyset`.

进一步，

`rho_q(m;S) = r`

当且仅当

`R_q^x(S)` 避开前 `r-1` 层，但命中第 `r` 层，即

`R_q^x(S) ∩ ( union_{t=1}^{r-1} Lambda_q(m,t) ) = emptyset`

且

`R_q^x(S) ∩ Lambda_q(m,r) != emptyset`.

### 证明

由定义，

`rho_q(m;S) >= r`

等价于对所有 `d in D(S)` 都有

`dist_q(md,0) >= r`.

而

`dist_q(md,0) < r`

当且仅当存在某个 `t in {1,2,...,r-1}` 使

`md = ±t mod q`.

因为 `m` 在模 `q` 下可逆，这又等价于

`d = ±t m^{-1} mod q`,

也就是

`d mod q in Lambda_q(m,t)`.

因此，存在某个差分把 `rho_q(m;S)` 压到 `< r`，
当且仅当 `R_q^x(S)` 命中了前 `r-1` 层逆元壳层中的至少一层。

把否定写出来，就得到

`rho_q(m;S) >= r`

当且仅当

`R_q^x(S)` 与这些低层逆元壳层全部不相交。

再把 `r` 与 `r+1` 的条件合并，就得到 `rho_q(m;S)=r` 的判据。证毕。

### 解释

这条命题很短，但含义非常直接：

- 以前我们是看 `m D(S) mod q` 什么时候第一次撞到原点附近；
- 现在可以等价地反过来看：
  **原始残基集合 `R_q^x(S)` 什么时候第一次撞到 `m` 的逆元壳层。**

这不是近似，也不是经验图像，而是**完全精确的等价改写**。

---

## 3. 推论 C1：什么时候某个分母 `q` 一定只能给 `1/q`

设窗口内允许分支集合为

`M_q(I) = { m : gcd(m,q)=1, a <= m/q <= b }`,

并假设

- `M_q(I)` 非空；
- 不存在零残基，即 `0 notin { d mod q : d in D(S) }`.

则下述两件事等价：

1. 所有允许分支都满足 `rho_q(m;S)=1`；
2. 对每个 `m in M_q(I)`，第一层逆元壳层都被命中，即
   `R_q^x(S) ∩ Lambda_q(m,1) != emptyset`.

换句话说，

> 如果每个 admissible `m` 的逆元对 `{±m^{-1}}` 都已经被差分残基命中，
> 那么这个分母 `q` 在当前窗口里就**不可能**给出超过 `1/q` 的最小间距。

这时不但 `rho_q^*(I;S)=1`，而且**所有 admissible `m` 都等优到 `1/q` 这一层**。

---

## 4. 推论 C2：什么时候立刻知道存在 `>=2/q` 的好分支

在同样假设 `M_q(I)` 非空且无零残基时，下述两件事等价：

1. 存在某个允许分支 `m in M_q(I)` 使 `rho_q(m;S) >= 2`；
2. 存在某个允许分支 `m in M_q(I)`，其第一层逆元壳层完全空缺，即
   `R_q^x(S) ∩ Lambda_q(m,1) = emptyset`.

也就是说：

> 只要某条 admissible 分支的逆元对 `{±m^{-1}}` 没被差分残基碰到，
> 就立刻知道这条分支至少能达到 `s_min >= 2/q`。

这是一个**非常实用的分母筛选规则**：

- 若所有 admissible 逆元对都被命中，则这个 `q` 可以直接判为“最多到 `1/q`”；
- 若至少有一对逆元缺位，则这个 `q` 立刻进入“值得深搜”的候选名单。

它没有给出一步闭式 `q=f(S)`，但已经不是黑箱扫参，而是一条**准确、快速、可解释**的筛分判据。

---

## 5. 对当前 5.4 例子的直接解释

当前集合固定为

`S=[1,4,6,10,15,18,22,27,31,37,40,46]`,

窗口固定为

`I=[0.2,0.3]=[1/5,3/10]`.

### 5.1 `q=29`

允许分支为

`M_29(I)={6,7,8}`.

对这三条分支，其第一层逆元对分别为

- `m=6`: `{5,24}`
- `m=7`: `{25,4}`
- `m=8`: `{11,18}`

而这三对都被 `R_29^x(S)` 命中。

所以由推论 C1 立刻得到：

- `rho_29(6)=rho_29(7)=rho_29(8)=1`
- 因而所有 admissible 分支都只能给出
  `s_min=1/29`

这就把 `q=29` 的“分支等优”现象压缩成了一个非常短的结构性解释：

> 不是因为 `m` 真地“从一般理论上消失了”，而是因为当前窗口里每条 admissible 分支的第一层逆元对都已经被差分残基命中，所以它们全部在第一层就被钉死。

### 5.2 `q=73`

允许分支为

`M_73(I)={15,16,17,18,19,20,21}`.

其中只有 `m=16` 的第一层逆元对在 `R_73^x(S)` 中缺位，
其余分支的第一层逆元对都已被命中。

因此由推论 C2 立刻知道：

- `m=16` 至少满足 `rho_73(16) >= 2`
- 其余分支仍停在 `rho=1`

进一步检查第二层逆元壳层，可见 `m=16` 在第二层被命中，
于是精确得到

- `rho_73(16)=2`
- `s_min(16/73)=2/73`

这就把 `q=73` 的反例也解释得很短：

> 它并不是推翻“有理 `(q,m)` 精确搜索”这条线，而只是说明：
> 第一层逆元对的覆盖在某些分母上会破，而一旦破掉，就会冒出真正更好的分支。

---

## 6. 这条命题对设计者到底有什么用

这条线最实用的地方，不是替代完整精确搜索，而是给出一个**极快的前置筛分**：

1. 先检查 `q` 是否出现零残基  
   若有，则这个分母直接碰撞，整层淘汰。

2. 若无零残基，只检查当前窗口内 admissible `m` 的逆元对 `{±m^{-1}}`  
   若全部被命中，则这个 `q` 被精确判定为“最多到 `1/q`”；  
   若某一对缺位，则对应 `m` 立刻成为 `>=2/q` 的候选好分支。

所以这条命题真正提供的是：

- 不是普适闭式最优分母；
- 而是一个**精确、短小、直接可用的第一层筛分规则**。

这已经比“电脑会搜”强很多，也比继续堆 shell taxonomy 更适合进当前主线。

---

## 7. 当前能写到哪里，不能写到哪里

### 现在可以稳写

1. `rho_q(m)` 可以精确改写为“差分残基集合第一次命中哪一层逆元壳层”的问题；
2. `q` 是否只能给 `1/q`，可由 admissible 逆元对是否全部被命中来精确判定；
3. `q` 是否存在 `>=2/q` 的更好分支，可由是否存在缺位的 admissible 第一层逆元对来精确判定。

### 现在还不能写过头

1. 不能写成“已经得到一般闭式 `q=f(S)`”；
2. 不能写成“对固定 `q`，`m` 一般都不重要”；
3. 不能写成“已经找到了所有高阶 branch-invariant 的统一结构”。

更准确的说法应当是：

> 我们已经找到一条对固定 `q` 非常短、并且对设计筛分立刻有用的精确判据；
> 但这还不是普适最优分母的闭式理论。

---

## 8. 这次推进后的最好落点

如果只保留一句最有价值的话，我会建议记成：

> 对固定分母 `q`，`rho_q(m)` 的大小可精确等价为差分残基集合 `R_q^x(S)` 第一次命中分支 `m` 的逆元壳层的层号。因此，在无零残基时，只要某条 admissible 分支的逆元对 `{±m^{-1}}` 缺位，就立刻知道该分支满足 `s_min >= 2/q`；反之若所有 admissible 逆元对都已被命中，则该分母在当前窗口内只能给出 `s_min = 1/q`。`

这条表述足够短、足够硬，而且对当前 `q=29` / `q=73` 两类现象都能一口解释清楚。
