# `q` 好坏的计数型上界/下界命题（分层推广版）

本文档把“为什么某个分母 `q` 好、为什么某个 `q` 坏”进一步整理成一组可证明的计数命题。
目标仍然不是一步写出普适闭式 `q=f(S)`，而是把“最优分母为什么好”尽可能推进到可证明的结构层面。

---

## 1. 记号

给定有限模式集合 `S`，其差分集合记为 `D=D(S)`。

对固定分母 `q`，定义模 `q` 的非零差分残基集合

- `R_q(S) = { d mod q : d in D }`
- `R_q^x(S) = R_q(S) \ {0}`

以及窗口 `I=[a,b]` 内允许的几何分支集合

- `M_q(I) = { m : gcd(m,q)=1, a <= m/q <= b }`
- `mu_q(I) = |M_q(I)|`

对任意允许分支 `m`，定义

`rho_q(m;S) = min_{d in D} dist_q(md,0),`

其中 `dist_q(x,0)` 表示整数 `x` 模 `q` 后到 `0` 的最短圆周距离。
相应地，固定分母下的最优层号为

`rho_q^*(I;S) = max_{m in M_q(I)} rho_q(m;S),`

最优最小间距为

`s_q^*(I;S) = rho_q^*(I;S) / q.`

---

## 2. 粗计数上界（原始版本）

若 `0 in R_q(S)`，则存在某个差分 `d in D` 满足 `q | d`，于是对任意允许分支 `m` 都有

`md equiv 0 mod q,`

从而

`rho_q^*(I;S) = 0.`

若 `0 notin R_q(S)`，定义

`nu_q(S) = |R_q^x(S)|.`

如果某个 `m` 满足 `rho_q(m;S) >= r`，那么集合 `m R_q^x(S)` 必须整体避开低壳层

`{1,2,...,r-1,q-r+1,...,q-1},`

该禁区共有 `2(r-1)` 个非零残基。因此必有

`nu_q(S) <= q - 2r + 1.`

从而得到粗上界

`rho_q^*(I;S) <= floor((q - nu_q(S) + 1)/2).`

这个版本已经能说明：`D mod q` 越拥挤，`q` 就越不可能太好。

---

## 3. gcd 分层

粗上界只看了“总共有多少个非零残基”，还没有利用这些残基在不同 `gcd(.,q)` 壳层中的分布。
为了再往前推进一步，定义

`Omega_{q,g} = { u mod q : gcd(u,q)=g },`

其中 `g` 是 `q` 的真因子，且 `g < q`。
该层的大小为

`|Omega_{q,g}| = phi(q/g).`

再定义当前集合在第 `g` 层上的占用数

`nu_{q,g}(S) = | R_q^x(S) ∩ Omega_{q,g} |.`

显然有

`sum_g nu_{q,g}(S) = nu_q(S).`

同时定义第 `r` 壳层以内、落在第 `g` 层上的“低壳禁区”大小

`beta_{q,g}(r) = | { u in Omega_{q,g} : dist_q(u,0) < r } |.`

如果记 `n=q/g`，那么也可写成

`beta_{q,g}(r) = 2 A_n(floor((r-1)/g)),`

其中

`A_n(t) = | { 1<=x<=t : gcd(x,n)=1 } |.`

这里的直观图像是：`q` 固定后，不同 `g` 对应不同的残基层；
离 `0` 近的残基，在每一层里各自形成一个“低壳禁区”。

---

## 4. 引理：单位元在每个 gcd 层上做置换

若 `m` 与 `q` 互质，则乘法 `u -> m u (mod q)` 保持 `gcd(u,q)` 不变，因此在每个层 `Omega_{q,g}` 上都给出一个置换。

### 证明

因为 `gcd(m,q)=1`，所以

`gcd(mu,q)=gcd(u,q).`

此外，乘以 `m` 在模 `q` 意义下可逆，逆映射由 `m^{-1}` 给出。
故其在每个 `Omega_{q,g}` 上都是双射。证毕。

这个引理的意义是：`m` 不会把某一层的残基挪到另一层去；
它只能在每一层内部重新排列。

---

## 5. 命题 U'：分层必要条件与更强上界

若某个允许分支 `m in M_q(I)` 满足

`rho_q(m;S) >= r,`

则对每个真因子 `g | q`，都必须有

`nu_{q,g}(S) <= phi(q/g) - beta_{q,g}(r).`

因此得到更强的分层上界：

`rho_q^*(I;S) <= max { r>=0 : nu_{q,g}(S) <= phi(q/g)-beta_{q,g}(r) for all g|q, g<q }.`

### 证明

固定一个 `g`。
由上面的置换引理，`m` 在层 `Omega_{q,g}` 上只是重排，不会改变该层中被占用的残基数。
若 `rho_q(m;S) >= r`，则所有被占用残基都必须避开该层内的低壳禁区，
而该禁区大小正是 `beta_{q,g}(r)`。
因此，被占用的残基数不可能超过该层剩余可用位置数

`phi(q/g) - beta_{q,g}(r).`

即

`nu_{q,g}(S) <= phi(q/g) - beta_{q,g}(r).`

对所有层同时成立，即得命题。证毕。

### 解释

这个命题比粗上界更强，因为它不再只问“总共有多少残基”，
而是逐层追踪“这些残基卡在了哪些 `gcd` 壳层里”。

---

## 6. 引理：固定一层时，坏分支的总数

下面把素数分母时的下界推广到一般复合分母。

固定一个非零残基 `u mod q`，记

`g = gcd(u,q),`
`n = q/g,`
`lambda_q(g) = phi(q) / phi(n) = phi(q) / phi(q/g).`

定义

`B_q(u,r) = { m in M_q(I) : dist_q(mu,0) < r }`

为使该残基掉入第 `r` 壳层以内的坏分支集合。
则有

`|B_q(u,r)| <= lambda_q(g) beta_{q,g}(r).`

### 证明

写 `u = g u_0`，其中 `gcd(u_0,n)=1`。
把单位群 `U_q = {m mod q : gcd(m,q)=1}` 通过模 `n` 约化到 `U_n`。
自然约化映射 `U_q -> U_n` 是满射，且每个纤维大小都等于

`lambda_q(g) = phi(q) / phi(n).`

另一方面，

`mu equiv g ( (m mod n) u_0 ) mod q.`

由于 `u_0` 在模 `n` 下可逆，随着 `m` 变化，`(m mod n) u_0` 只是对 `U_n` 的一个置换。
因此，在全部单位分支中，使 `mu` 落入第 `r` 壳层以内的分支数，
恰好等于每个目标低壳残基的纤维数 `lambda_q(g)` 乘以该层低壳残基总数 `beta_{q,g}(r)`。

把它再与窗口内允许分支集合 `M_q(I)` 相交，只会更少，不会更多。
故

`|B_q(u,r)| <= lambda_q(g) beta_{q,g}(r).`

证毕。

## 7. 命题 L'：一般复合分母情形的计数型下界

若 `0 notin R_q(S)`，并且对某个整数 `r>=1` 有

`mu_q(I) > sum_{g|q, g<q} nu_{q,g}(S) lambda_q(g) beta_{q,g}(r),`

则必存在某个允许分支 `m in M_q(I)` 使得

`rho_q(m;S) >= r.`

从而得到一般复合分母下界

`rho_q^*(I;S) >= max { r>=1 : mu_q(I) > sum_g nu_{q,g}(S) lambda_q(g) beta_{q,g}(r) }.`

### 证明

对每个 `u in R_q^x(S)`，其坏分支集合为 `B_q(u,r)`。
若某个 `m` 不属于任何 `B_q(u,r)`，就说明对所有 `u` 都有

`dist_q(mu,0) >= r,`

即

`rho_q(m;S) >= r.`

因此只要并集

`union_{u in R_q^x(S)} B_q(u,r)`

不能覆盖全部允许分支 `M_q(I)`，就必存在这样的好分支。

由上一个引理，对第 `g` 层上的每一个 `u`，都有

`|B_q(u,r)| <= lambda_q(g) beta_{q,g}(r).`

再对所有层用并集上界，得到

`| union_u B_q(u,r) | <= sum_g nu_{q,g}(S) lambda_q(g) beta_{q,g}(r).`

若右边严格小于 `mu_q(I)=|M_q(I)|`，则并集不可能覆盖全部允许分支，
故至少存在一个允许分支 `m` 使得 `rho_q(m;S) >= r`。证毕。

### 解释

这个下界的含义是：

- `nu_{q,g}(S)` 记录第 `g` 层里有多少种差分残基在“制造约束”；
- `beta_{q,g}(r)` 记录该层低壳禁区到底有多大；
- `lambda_q(g)` 记录从模 `q/g` 抬升回模 `q` 时，一个目标残基会对应多少条单位分支。

因此，复合分母情形下，一个 `q` 是否“至少不差”，
取决于每一层上的残基拥挤度、低壳大小和抬升倍数三者的共同作用。

---

## 8. 素数情形是命题 L' 的特例

若 `q` 为素数，则唯一可能的非零层只有 `g=1`，并且

- `phi(q/g)=phi(q)=q-1`
- `lambda_q(1)=1`
- `beta_{q,1}(r)=2(r-1)`

于是命题 L' 自动退化为

`mu_q(I) > 2(r-1) nu_q(S)  =>  rho_q^*(I;S) >= r,`

这正是之前的素数分母下界命题。

---

## 9. 当前集合在 `q=29` 上的解释

对当前集合

`S=[1,4,6,10,15,18,22,27,31,37,40,46]`

和窗口

`I=[0.2,0.3]=[1/5,3/10]`,

有

- `M_29(I) = {6,7,8}`，故 `mu_29(I)=3`
- `29` 为素数，所以只有 `g=1` 这一层
- `nu_{29,1}(S)=27`

对 `r=1`，

- 分层上界要求 `27 <= 28 - 0`，成立
- 对 `r=2`，要求 `27 <= 28 - 2`，不成立

所以分层上界直接给出

`rho_29^*(I;S) <= 1.`

另一方面，由复合分母下界（在这里退化为素数下界）可得

`rho_29^*(I;S) >= 1.`

故上下界碰头，得到精确值

`rho_29^*(I;S)=1,`

从而

`s_29^*(I;S)=1/29.`

---

## 10. 这些命题现在已经做到什么

它们已经能做到：

- 说明为什么某些 `q` 一眼就不可能好
- 在很多情形下，仅用计数信息就把 `rho_q^*` 直接夹成精确值
- 把“`q` 的好坏”从经验观察推进到可证明的残基层约束
- 把素数分母下界推广到一般复合分母情形

它们还做不到：

- 一步写出普适闭式 `q=f(S)`
- 完全消除 `m` 的作用
- 给出类似连续满载情形那种一行即得的统一解析式

---

## 11. 当前最稳妥的一句话总结

> 对一般有限模式集合，分母 `q` 的优劣已经可以由一组可计算的分层计数量来刻画：每个 `gcd` 壳层中的差分残基占用数 `nu_{q,g}(S)`、该层低壳禁区大小 `beta_{q,g}(r)`，以及由模 `q/g` 抬升回模 `q` 时的纤维倍数 `lambda_q(g)`。这些量共同给出了 `rho_q^*(I;S)` 的严格上界与严格下界，从而把“最优分母为什么好”从数值现象推进到了可证明的计数结构层面。
