# 可供论文引用的命题-推论表述：精确坏并集判据

本文档把“精确坏并集”这条线压缩成更适合论文或 Claude 直接吸收的命题-推论表述。
目标不是展开全部技术细节，而是给出一套短而硬的数学骨架。

---

## 1. 定义

设有限模式集合为 `S`，其差分集合为 `D(S)`。
固定分母 `q` 与几何窗口 `I=[a,b]`，定义允许分支集合

`M_q(I)= { m : gcd(m,q)=1, a <= m/q <= b }`

及其大小

`mu_q(I)=|M_q(I)|`.

对每个非零差分残基 `u in R_q^x(S)` 与每个整数 `r>=1`，定义坏分支集合

`B_q(u,r)= { m in M_q(I) : dist_q(mu,0) < r }`.

再定义精确坏并集大小

`U_q(r)= | union_{u in R_q^x(S)} B_q(u,r) |`.

这里 `U_q(r)` 不是上界，而是窗口内真实被“至少一个差分残基”判坏的分支总数。

---

## 2. 命题 P1：精确坏并集判据

对任意固定 `q` 与 `r>=1`，有

`rho_q^*(I;S) >= r  <=>  U_q(r) < mu_q(I)`.

### 证明

由定义，

`rho_q(m;S) >= r`

当且仅当对所有 `u in R_q^x(S)` 都有

`dist_q(mu,0) >= r`,

这等价于

`m notin B_q(u,r)` for all `u`,

再等价于

`m notin union_{u in R_q^x(S)} B_q(u,r)`.

因此，存在某个允许分支 `m in M_q(I)` 使得 `rho_q(m;S) >= r`
当且仅当坏并集没有覆盖全部允许分支，即

`U_q(r) < mu_q(I)`.

证毕。

### 解释

这个命题把“存在好分支”完全等价成一个覆盖问题：

- 若坏并集没有盖满 `M_q(I)`，就至少有一条幸存分支；
- 若坏并集已经盖满 `M_q(I)`，则半径 `r` 已经不可实现。

---

## 3. 推论 C1：最佳层号的精确判定

对任意固定 `q`，有

`rho_q^*(I;S)=r`

当且仅当

`U_q(r) < mu_q(I)` 且 `U_q(r+1)=mu_q(I)`.

### 证明

由命题 P1，

- `U_q(r) < mu_q(I)` 等价于 `rho_q^*(I;S) >= r`
- `U_q(r+1) = mu_q(I)` 等价于 `rho_q^*(I;S) < r+1`

两者合并即得

`r <= rho_q^*(I;S) < r+1`,

故

`rho_q^*(I;S)=r`.

证毕。

### 解释

这说明：一旦能把坏并集算精确，就可以不用粗上界/粗下界，直接给出 `rho_q^*` 的精确值。

---

## 4. 推论 C2：`rho_q^*=1` 的简洁判定

若

- `mu_q(I) > 0`
- `U_q(2)=mu_q(I)`

则

`rho_q^*(I;S)=1`.

### 证明

对任意非零差分残基 `u`，都有

`B_q(u,1)=emptyset`,

所以

`U_q(1)=0 < mu_q(I)`.

再结合 `U_q(2)=mu_q(I)`，由推论 C1 立即得到

`rho_q^*(I;S)=1`.

证毕。

### 解释

这是当前例子中最常用的版本：

- 第 1 层总是可行，因为半径 `1` 时根本没有非零坏事件；
- 真正决定 `rho_q^*` 是否大于 `1` 的，是半径 `2` 时坏并集是否已经覆盖全部允许分支。

---

## 5. 模式分类语言

为描述坏并集的内部结构，可定义坏模式映射

`P_{q,r}(u)=B_q(u,r) subseteq M_q(I)`.

于是不同残基 `u` 被分成若干模式类

`Gamma_{q,r}(P)= { u in R_q^x(S) : P_{q,r}(u)=P }`.

若很多残基对应同一坏模式，则说明坏事件高度重叠；
若只出现少数几个极小模式，但这些模式的并集已经覆盖全部允许分支，
则会出现“稀薄但完全覆盖”的失败机制。

---

## 6. 当前例子中的 `q=35`

对集合

`S=[1,4,6,10,15,18,22,27,31,37,40,46]`

和窗口

`I=[0.2,0.3]`,

有

`M_35(I)={8,9}`.

对 `r=2`，坏模式分类结果为：

- `P_{35,2}(13)=P_{35,2}(22)={8}`
- `P_{35,2}(4)=P_{35,2}(31)={9}`
- 其余非零差分残基对应空模式 `emptyset`

因此

`U_35(2)= | {8} union {9} | = 2 = mu_35(I)`,

而

`U_35(1)=0 < 2`.

由推论 C1 或推论 C2 立即得到

`rho_35^*(I;S)=1`.

### 解释

这说明 `q=35` 的失效机制不是“允许分支太多太杂”，而恰恰相反：

- 只有两条允许分支 `8,9`
- 只有两类极小坏模式 `{8}` 与 `{9}`
- 但这两类模式的并集刚好覆盖全部允许分支

因此 `q=35` 是一种典型的“稀薄但完全覆盖”型分母。

---

## 7. 论文中最安全的一句话

> 对固定分母 `q`，可将“是否存在满足给定分辨层号 `r` 的几何分支”精确改写为一个坏分支覆盖问题：若所有低壳坏分支集合在允许分支集合 `M_q(I)` 上的精确并集大小记为 `U_q(r)`，则有 `rho_q^*(I;S) >= r` 当且仅当 `U_q(r) < mu_q(I)`。因此，一旦 `U_q(r)` 与 `U_q(r+1)` 可被精确计算，最佳层号 `rho_q^*(I;S)` 即可由纯覆盖结构直接判定。当前随机集合在 `q=35` 时正属于此类情形。`

---

## 8. 当前最克制的结论边界

这套结果已经足够说明：

- 对固定 `q`，最佳层号并不一定需要靠连续扫描决定；
- 在很多情形下，它可以由精确坏并集结构直接判定；
- `q=35` 这类先前“只差半步”的分母，也能用这种方法直接钉死。

但它仍然**不等于**：

- 已经得到普适闭式 `q=f(S)`
- 已经完全消除了 `m` 的作用
- 已经找到了对所有集合都统一简洁的一步解析公式
