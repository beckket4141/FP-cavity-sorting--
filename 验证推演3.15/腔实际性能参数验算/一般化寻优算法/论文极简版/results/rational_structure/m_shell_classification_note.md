# 固定 `q` 时对 `m` 的壳层分类

本文档回答一个更细的问题：

> 对固定分母 `q`，哪些分支 `m` 真正等价？

这里的“等价”至少有两种层次：

- **精确等价**：它们把差分残基集合送到完全相同的模 `q` 位置集合；
- **壳层等价**：它们虽然送到的具体残基不同，但在每个距离壳层上的占用计数完全相同，因此给出相同的 `rho_q(m)` 与相同的壳层画像。

---

## 1. 单位群作用

固定 `q` 后，模 `q` 的单位群记为

`U_q = { m mod q : gcd(m,q)=1 }`.

对任意差分残基集合 `R_q^x(S)`，单位群通过乘法作用：

`m : R_q^x(S) -> m R_q^x(S).`

这给出了一个很自然的群作用视角。

---

## 2. 精确等价

定义

`m ~_exact m'`

当且仅当

`m R_q^x(S) = m' R_q^x(S)`.

### 命题 E1

有

`m ~_exact m'  <=>  m^{-1} m' in Stab_q(R_q^x(S)),`

其中稳定子定义为

`Stab_q(R_q^x(S)) = { s in U_q : s R_q^x(S) = R_q^x(S) }`.

### 解释

这说明固定 `q` 时，精确等价类就是稳定子的陪集。
如果稳定子很小，那么大多数 `m` 都是精确不等价的；
如果稳定子较大，则会出现许多完全相同的分支。

---

## 3. 壳层等价

对每个 `m`，定义壳层计数签名

`h_q(m;r) = | m R_q^x(S) ∩ Sigma_q(r) |,`

其中

`Sigma_q(r) = {r, q-r}`.

再把全部层号拼成壳层签名向量

`H_q(m) = (h_q(m;1), h_q(m;2), ..., h_q(m; floor(q/2))).`

定义

`m ~_shell m'`

当且仅当

`H_q(m) = H_q(m').`

### 命题 E2

若 `m ~_shell m'`，则

`rho_q(m;S) = rho_q(m';S)`.

### 证明

`rho_q(m;S)` 恰好是壳层签名中第一个非零分量出现的层号。
若签名完全一致，则第一个非零层号也一致。证毕。

### 解释

因此：

- 精确等价一定推出壳层等价；
- 但壳层等价不一定推出精确等价。

前者更细，后者更接近我们真正关心的 `rho_q(m)`。

---

## 4. 与 `q=35` 这类半步案例的关系

当前下界之所以有时偏松，本质上是因为它把许多“坏分支集合”用并集上界粗略相加了。
若想在 `q=35` 这类案例上再往前推进，就需要更细地知道：

1. 允许分支 `m` 到底分成几个精确类；
2. 这些类是否进一步合并成更少的壳层类；
3. 哪些原始差分在每个类里最先打到低壳层；
4. 不同差分诱导的坏分支集合之间到底重叠了多少。

因此，固定 `q` 的 `m` 分类并不是旁支，而是推进 `q=35` 这类“只差半步”的直接工具。

---

## 5. 当前最稳妥的一句话总结

> 固定分母 `q` 后，分支参数 `m` 的作用可视为单位群 `U_q` 对差分残基集合 `R_q^x(S)` 的乘法作用。由此自然出现两层分类：一层是由稳定子陪集给出的精确等价类，另一层是由距离壳层计数给出的壳层等价类。前者刻画“哪些 `m` 完全相同”，后者刻画“哪些 `m` 至少在分辨能力上相同”。对 `q=35` 这类计数上下界尚未碰头的分母，进一步理解 `m` 的这两层分类，是继续收紧下界的最直接抓手。
