## 二、问题定义

设目标模式总阶数集合为

$$S = \{N_1, N_2, \dots, N_M\}, \quad N_1 < N_2 < \cdots < N_M, \quad N_i \in \mathbb{Z}^+.$$

对任意给定几何步长 $k \in (0, 1/2)$，定义模式在一个 FSR 内的归一化位置为

$$\mathrm{pos}(N) = (Nk) \bmod 1.$$

该集合的最小圆周间距为

$$s_{\min}(k; S) = \min_{i < j} \min\bigl(|\mathrm{pos}(N_i) - \mathrm{pos}(N_j)|,\; 1 - |\mathrm{pos}(N_i) - \mathrm{pos}(N_j)|\bigr).$$

**优化目标**：在给定几何窗口 $I = [a, b] \subset (0, 1/2)$ 内，找到使 $s_{\min}(k; S)$ 最大的工作点 $k^*$，进而给出最小所需精细度

$$\mathcal{F}_{\min} = \frac{\tau_0}{s_{\min}(k^*; S)}.$$

这与连续满载问题的区别在于：$S$ 不再是 $\{1, \dots, N\}$ 形式，差分集合 $D(S) = \{N_j - N_i : i < j\}$ 不再具有连续满载的特殊结构，因此 §5.1 的解析最优分支定理不再直接适用。

## 三、已经严格建立的数学结论链

以下五条结论均已给出完整证明（证明文本见 `results/rational_structure/theorem_style_note.md`），并经独立 Python 脚本逐条数值验证。

### 结论 1：差分集合约化

$$s_{\min}(k; S) = \min_{d \in D(S)} \|dk\|,$$

其中 $\|x\|$ 表示 $x$ 到最近整数的距离。

**意义**：问题的核心对象不是模式个数 $M$，而是差分集合 $D(S)$。

### 结论 2：有理候选点的精确评分公式

若 $k = m/q$，$\gcd(m, q) = 1$，则

$$s_{\min}(m/q; S) = \frac{1}{q} \cdot \rho_q(m; S),$$

其中

$$\rho_q(m; S) = \min_{d \in D(S)} \mathrm{dist}_q(md, 0), \quad \mathrm{dist}_q(r, 0) = \min(r \bmod q,\; q - r \bmod q).$$

**意义**：一旦把候选点限制在 $k = m/q$，评分完全可以用整数模运算精确完成。

### 结论 3（定理 1）：最优点必可在有理数处取得

设几何搜索窗口为有理闭区间 $I = [a, b] \subset (0, 1/2)$。则 $s_{\min}(k; S)$ 在 $I$ 上的全局最大值一定可以在某个有理数点 $k^* = m/q$ 处取得。

**证明思路**：$s_{\min}(k)$ 是有限个 V 形函数 $|dk - n|$ 的逐点最小值，构成分段线性下包络。其极值只能出现在折点 $n/d$（有理数）或不同仿射分支的交点（仍为有理数）处，在任何开区间内部都只是某个非零斜率仿射函数，不可能取极大。

### 结论 4（定理 2）：最优分母存在显式上界

记 $D_{\max} = \max D(S)$。定义

$$Q_I(S) = \max\bigl(\mathrm{den}(a),\; \mathrm{den}(b),\; 2D_{\max}\bigr),$$

其中 $\mathrm{den}(x)$ 表示有理数 $x$ 约分后的分母。则

$$\max_{k \in I} s_{\min}(k; S) = \max_{1 \le q \le Q_I(S)} \max_{\substack{m:\; \gcd(m,q)=1 \\ a \le m/q \le b}} \frac{1}{q}\,\rho_q(m; S).$$

**意义**：连续优化问题已经严格降为有限 $(q, m)$ 集合上的精确搜索。不需要无限精度的连续数值优化。

### 结论 5：MIS 与本问题的关系

- MIS 解决的是另一个问题：**固定几何后，最多保留哪些模式**。
- §5.4 当前要解决的是：**固定目标集合后，最优几何在哪里**。
- 对后者，MIS 不是主线工具。MIS 可以保留为"若某个腔体参数已经给定，最多能兼容多少模式子集"的补充说明，但不应再作为 §5.4 的叙事核心。

## 四、当前例子的精确数值结果

**模式集合**（随机选取的 12 个总阶数）：

$$S = [1, 4, 6, 10, 15, 18, 22, 27, 31, 37, 40, 46]$$

**差分集合**：$|D(S)| = 35$，$D_{\max} = 45$。

**搜索窗口**：$I = [0.2, 0.3] = [1/5, 3/10]$（第五章正文承认的"适中主分支"几何窗口）。

**分母上界**：$Q_I(S) = \max(5, 10, 90) = 90$。

**精确最优解**（由有限 $(q, m)$ 穷举确认）：

| 量 | 值 |
|---|---|
| $k^*$ | $7/29 \approx 0.2414$ |
| $(L/R)^*$ | $\sin^2(\pi \cdot 7/29) \approx 0.4729$ |
| $s_{\min}^*$ | $1/29 \approx 0.03448$ |
| $\mathcal{F}_{\min}$（$\tau_0 = 3$） | $87$ |
| $\mathcal{F}_{\min}$（$\tau_0 = 5$） | $145$ |

**等价分支**：在同一分母 $q = 29$ 下，$6/29$、$7/29$、$8/29$ 三个分支均给出相同的 $s_{\min} = 1/29$。最终选 $7/29$ 是因为它最接近 $L/R = 0.5$（$|L/R - 0.5| = 0.027$），符合"避免极端几何分支、优先中等几何比"的工程原则。

**限制性差分**：$d = 4, 25, 33$（三个差分同时达到 $s_{\min}$，对应多个模式对，其中包括 $(15, 40)$）。

**独立验证方式**：
1. 穷举 $q \le 90$ 的全部有理候选 $(q, m)$
2. 百万点密集连续扫描
3. 两种方法给出完全一致的结果

## 五、进一步的结构性分析（可选引用）

以下结果不是 §5.4 正文必须引用的，但如果篇幅允许或需要更深入的说明，可以酌情使用。

### 5.1 分层计数上下界

对固定分母 $q$，可以用差分残基在模 $q$ 意义下各 $\gcd$ 壳层中的分布，给出最优层号 $\rho_q^*(I; S)$ 的严格上界和下界。当两者碰头时，$\rho_q^*$ 被纯计数直接钉死。

对当前例子：
- $q = 29$（素数）：$\nu_{29}(S) = 27$，$\mu_{29}(I) = 3$，上下界在 $r = 1$ 碰头，故 $\rho_{29}^* = 1$，$s_{29}^* = 1/29$。
- $q = 32$：分层上界在 $g = 1$ 层的第二层号处被挤爆，也碰头给出 $\rho_{32}^* = 1$。

详见 `results/rational_structure/q_counting_bounds_note.md`。

### 5.2 精确坏并集判据

对某些分母（如 $q = 35$），分层计数上下界差半步。此时可以通过精确计算坏分支集合的并集大小 $U_q(r)$ 来直接判定：

$$\rho_q^*(I; S) = r \iff U_q(r) < \mu_q(I) \text{ 且 } U_q(r+1) = \mu_q(I).$$

对 $q = 35$：$M_{35}(I) = \{8, 9\}$，半径 $r = 2$ 时两类极小坏模式 $\{8\}$ 与 $\{9\}$ 的并集刚好覆盖全部允许分支，故 $\rho_{35}^* = 1$。

详见 `results/rational_structure/paper_ready_bad_union_propositions.md`。

### 5.3 $q = 73$ 反例：$m$ 一般不可省略

对 $q = 73$，$m = 16$ 给出 $s_{\min} = 2/73$，而 $m = 15, 17, 18, 19, 20, 21$ 只给 $1/73$。

这说明"只搜分母 $q$、$m$ 自动无关"的更强命题是**错误的**。正文中如需提及，应明确指出固定 $q$ 后仍需遍历允许的互质 $m$。

### 5.4 百组随机验证

对 100 组随机 12 元模式集合，"密集连续搜索"和"有理候选搜索"的结果 100% 吻合。这说明定理 1 的有理最优性不是个别巧合，而是普适结构。

详见 `results/random_validation/summary.md`。

## 七、推荐的 §5.4 正文写法口径

按 CANON_01 冻结的 §5.4 职责（"一般模式集合与受限几何的扩展说明"），推荐叙述逻辑如下：

### 第一段：问题转向

前文（§5.1–§5.3）针对连续满载模式集合 $S_N = \{1, \dots, N\}$ 建立了解析设计理论并完成了实验闭环。然而在更一般的应用场景中，目标模式集合可能是非连续的——例如只需分选若干特定 OAM 阶数。此时连续满载的解析最优分支 $k = m/N$ 与容量上界 $s_{\min} = 1/N$ 不再直接适用，需要发展更一般的设计方法。

### 第二段：差分集合约化与有理最优定理

对一般有限模式集合 $S$，$s_{\min}(k; S)$ 可约化为差分集合 $D(S)$ 驱动的圆周距离问题（结论 1）。进一步地，由于 $s_{\min}(k)$ 在有界几何窗口内是由有限个有理断点构成的分段线性下包络，其全局最优工作点必可在有理数处取得（定理 1），且其分母存在显式上界 $Q_I(S) = \max(\mathrm{den}(a), \mathrm{den}(b), 2D_{\max})$（定理 2）。相应地，原本的连续几何扫描可以严格降为对有限有理候选 $(q, m)$ 的精确比较。

### 第三段：当前例子

作为具体示例，取随机模式集合 $S = [1, 4, 6, 10, 15, 18, 22, 27, 31, 37, 40, 46]$。在适中主分支窗口 $k \in [0.2, 0.3]$ 内，$D_{\max} = 45$，故 $Q_I(S) = 90$，只需搜索 $q \le 90$ 的有限有理候选。精确搜索给出最优解 $k^* = 7/29$，对应 $(L/R)^* \approx 0.4729$，$s_{\min}^* = 1/29$。在 $\tau_0 = 3$ 和 $\tau_0 = 5$ 下，最低所需精细度分别为 87 和 145。

### 第四段（可选）：MIS 的补充地位

上述方法解决的是"固定目标集合后，最优几何在哪里"。若问题反过来——给定某个已有腔体的几何参数，希望从更大的候选集合中选出最多可兼容的模式子集——则仍可借助冲突图与最大独立集（MIS）框架。两类问题互补而非替代。

### 第五段：收束

由此说明，一般有限模式集合的最优几何设计问题并非只能依赖黑箱数值扫描，而是可以在有限有理候选上被精确求解。这一结论为未来面向特定任务需求的非标准模式分选器件设计提供了严格的方法基础。
