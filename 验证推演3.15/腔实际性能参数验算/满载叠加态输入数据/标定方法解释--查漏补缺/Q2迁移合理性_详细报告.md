# Q2 迁移合理性详细报告

## 1. 本轮任务与边界

本轮只处理审稿质疑 Q2：

> 标定时 `FP` 锁在模式 `j` 的共振点，而满载使用时模式 `j` 往往处于离共振漏透状态；此时为什么还能沿用标定得到的 `S_{ij}`？

硬边界如下：

- 不修改正文。
- 不修改原始实验数据文件。
- 只在 `标定方法解释--查漏补缺` 目录下新增脚本与分析结果。
- 不把 Q2 擅自扩展成“所有系统误差都已经完全排除”。

## 2. 先把你的标定定义写准

你刚补充的实验定义非常关键，必须作为 Q2 回应的起点，而不能被模糊化。

标定矩阵 `S` 的第 `k` 列，测量方式是：

1. 产生端 `SLM` 产生纯的 `l=k`。
2. `FP` 腔锁定态也是 `l=k`。
3. 在这个固定条件下，检测端遍历全部通道 `l=0~8`。

因此，`S_{ik}` 的物理含义首先是：

> 在“纯参考态 `l=k` 经 `FP` 共振透射后到达检测端”的条件下，检测通道 `i` 的有效读出响应。

这说明你的标定矩阵不是随意构造出来的经验矩阵，而是专门为了剥离检测链路不均匀性而设计的“纯模参考响应矩阵”。这一点本身是成立的。

## 3. Q2 真正要回答的不是“标定对不对”，而是“能不能迁移”

从审稿人角度看，Q2 实际分成两层：

### 第一层：标定目的是否合理

这一层你的答案是成立的：

- 因为标定时产生端和 `FP` 锁定态同为 `l=k`；
- 输入态已经是高纯度 `l=k`；
- `FP` 在共振点又做了一次 `l=k` 的频域选择；
- 所以测得的 `S_{:k}` 的确是在刻画“检测系统对参考模式 `k` 的全通道响应”。

### 第二层：为什么这列 `S_{:k}` 可以迁移到离共振漏透

真正危险的是这一层。仅仅说明“标定时很纯”，还不足以自动推出“满载时离共振漏透也能用同一列 `S_{:k}`”。

要完成这一步，必须再补一个物理桥梁：

> 对理想 `FP` 腔的横模本征态而言，离共振失谐改变的是该模式的复传输系数（或者在功率层面表现为 Airy/Lorentz 透射系数），而不是它的横向本征轮廓本身。

换句话说，若把第 `k` 个横模写成 `u_k(r)`，则锁频条件改变时应是

```text
u_k(r)  ->  h_k(Δ) · u_k(r)
```

而不是

```text
u_k(r)  ->  某个新的横向形状 v_k(r, Δ)
```

只有在这个前提下，标定时测得的那一列 `S_{:k}` 才能在满载反演里继续代表“模式 `k` 被检测端读出的方式”。

## 4. 当前仓库里已经有一条可用的理论线

本仓库正文第二章其实已经给了这条桥梁的上半句。

在 [ch02_lg_oam_theory.tex](/D:/自制软件/1.thesis/My_nju_thesis-master/thesis/chapters/ch02_lg_oam_theory.tex#L293) 中，正文已经写到：

- `FP` 的选择性透射由相位匹配决定；
- 该过程“不涉及振幅或波前的不可逆变换”；
- 因而透射光保持原始空间相位结构。

如果把这句话在 Q2 语境下进一步收紧，它实际支持的是：

- 对一个给定的腔本征横模，锁频偏离共振时，主要变化应是透射幅度随失谐衰减；
- 该模式的横向结构本身不应因“只是离开共振点”而被改写成另一个模式。

第五章正文也已经把离共振串扰当成 Airy/Lorentz 尾巴在处理，见 [ch05_fp_design_and_validation.tex](/D:/自制软件/1.thesis/My_nju_thesis-master/thesis/chapters/ch05_fp_design_and_validation.tex#L120)。因此，若正文一方面用 Airy 尾巴讨论离共振漏透，另一方面又在附录里暗示离共振时模式形状可能完全变掉，这两边会互相打架。

所以从全文内部逻辑看，Q2 更合理的修补方向不是否定你的标定方法，而是把这个“只改幅度、不改横向轮廓”的迁移前提显式说出来。

- 各 run 的 `full9_matrix_with_uncertainty.xlsx`

### 5.2 前向模型

对每个 run、每个锁定列 `j`，构造

```text
x_theory^(j)[k] = alpha_j * T_peak[k] * Airy(s_kj; F)
y_theory^(j)    = S * x_theory^(j)
```

其中：

- `T_peak[k]` 由该 run 的单模透射率工作簿直接读取；
- `s_kj` 由该 run 的锁定波长恢复的共振位置计算得到；
- `F` 先固定取正文的 `32.21`，再允许做一个全局单参数拟合作交叉检查；
- `alpha_j` 是每个锁定列一个标量，只吸收总光强尺度差异，不改变通道结构。

这个模型严格对应你想主张的迁移假设：

- 标定列 `S_{:k}` 仍然代表模式 `k` 的检测响应指纹；
- 离共振时模式 `k` 只乘上一个标量 Airy 透射系数。

## 6. 结果：数据明显支持“可迁移”

### 6.1 全局结果

对 3 个 run 一起拟合时：

- 最优共享精细度约为 `31.169`
- 对原始满载读出矩阵 `Y` 的全局相对残差约为 `0.0141`
- 若直接固定使用正文值 `F=32.21`，残差也只有 `0.0143`

这说明：

- 数据并不需要引入一个全新的“离共振形变响应矩阵”才能解释；
- 仅用“参考标定列 `S` + Airy 幅度衰减”已经足够接近真实原始读出。

### 6.2 分 run 结果

固定 `F=32.21` 时：

- Run 1：原始 `Y` 相对残差 `0.0118`
- Run 2：原始 `Y` 相对残差 `0.0178`
- Run 3：原始 `Y` 相对残差 `0.0121`

并且各锁定列归一化后的列向量相似度非常高：

- Run 1：平均余弦相似度 `0.99972`，最小值 `0.99821`
- Run 2：平均余弦相似度 `0.99951`，最小值 `0.99797`
- Run 3：平均余弦相似度 `0.99974`，最小值 `0.99909`

这组数说明，不只是总功率量级，连每个锁定列在 9 个检测通道上的读出形状都被这套迁移模型复现得很好。

### 6.3 反面模型对照

脚本还测试了两个自然但较弱的替代解释：

1. `target-column` 模型  
   把某个锁定列里的全部漏透都强行视为“长得像目标锁定态那一列 `S_{:j}`”。

2. `diagonal-only` 模型  
   只保留 `diag(S)`，忽略完整的全通道响应结构。

固定 `F=32.21` 时，它们对原始 `Y` 的相对残差分别为：

- Run 1：迁移模型 `0.0118`，`target-column` `0.0337`，`diagonal-only` `0.0167`
- Run 2：迁移模型 `0.0178`，`target-column` `0.0365`，`diagonal-only` `0.0219`
- Run 3：迁移模型 `0.0121`，`target-column` `0.0341`，`diagonal-only` `0.0184`

这意味着：

- 数据明显更偏向“每个离共振漏透模式仍保留各自的标定列指纹”；
- 而不是“所有漏透都长得像当前锁定态”；
- 也不是“只做简单对角效率校正就够了”。

这正是 Q2 所需要的那条数据旁证。

## 7. 为什么预测的 `ER_sum` 还是略高于实验

用这套迁移模型预测的 `X` 矩阵，其平均 `ER_sum` 会比实验值略高：

- Run 1：实验 `11.576 dB`，预测 `12.029 dB`
- Run 2：实验 `11.517 dB`，预测 `12.032 dB`
- Run 3：实验 `11.123 dB`，预测 `12.031 dB`

这不是坏事，反而说明当前数据更符合下面这种结构：

- **主结构**：由“共振位置 + 单模峰值透射率 + Airy 尾巴 + 标定矩阵 `S` 迁移”决定；
- **剩余偏差**：来自径向寄生模、腔模匹配误差、高阶模式额外损耗、检测端残余非理想等工程退化。

也就是说，Q2 的迁移假设解释了大部分结构；剩下的差距更适合归入工程非理想，而不是归入“标定矩阵方法本身不成立”。

## 8. 当前最稳的结论

本轮可以安全主张：

1. 你的标定矩阵测量方法本身是合理的，目标就是在纯模参考条件下量化检测链路响应。
2. Q2 真正需要补的是“从纯模参考态到离共振漏透态”的迁移桥梁，而不是否定标定设计本身。
3. 用 run 内实测峰位、run 内实测单模峰值透射率和正文精细度 `F=32.21` 构造的前向模型，已经能把原始满载读出 `Y` 复现到约 `1%~2%` 的相对残差。
4. 数据明显更支持“同一模式在离共振时只改幅度、不改标定列指纹”的解释，而不支持两个简单替代模型。

## 9. 仍然不能说过头的地方

以下内容本轮不建议说得过满：

1. 不能说“Q2 已被严格证明，不存在任何额外系统误差”。
2. 不能说“离共振时空间模式绝对不可能受腔镜色散影响”。
3. 不能说“既然迁移模型效果好，`S` 就纯粹只等于检测系统，不再含任何器件相关因素”。

更稳妥的说法应是：

> 在当前 9 模数据口径下，纯模参考条件下获得的响应列能够与基于实测峰位和 Airy 失谐系数的前向模型一起，定量重建满载原始读出。这说明标定列对离共振漏透分量具有良好的可迁移性；剩余偏差更适合归因于径向寄生模、模匹配误差和高阶通道额外损耗等工程非理想，而非标定框架本身失效。

## 10. 最终判断

如果只看 Q2，本轮推演给出的结论是偏正面的：

- 你的标定方法方向没有问题；
- 审稿人的核心担忧不应被回成“我们只是为了消除检测系统问题”，而应进一步补上“为什么纯模标定列可以迁移到离共振漏透态”；
- 而这一步，现在已经有了可复算的数据支持。

换句话说，Q2 目前最好的处理方式不是防守式解释，而是把它收紧成一句更准确的话：

> 标定矩阵 `S` 不是在任意混合条件下直接定义出来的经验修正项，而是在“产生端 `l=k`、FP 锁定态 `l=k`、检测端遍历全部通道”这一纯模参考条件下测得的全通道响应指纹。对于当前实验中观测到的离共振漏透，其原始读出可以由“同一响应指纹 + 标量失谐透射系数”很好地复现，因此该矩阵在满载反演中的迁移使用具有明确的数据支持。
