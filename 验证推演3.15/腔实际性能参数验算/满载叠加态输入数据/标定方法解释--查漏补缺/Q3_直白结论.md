# Q3 直白结论

这份说明只回答一个问题：

`l=8` 这个低效率通道，会不会把论文最后的成功率结果变得不可信？

## 1. 先说最核心的结论

这件事要分成三句话来说。

1. `l=8` 确实是最弱、最敏感的检测通道，这一点审稿人的直觉没有错。
2. 但“因为 `l=8` 的检测效率只有约 `3.8%`，所以 `1%` 的标定误差一定会放大成 `25%` 的最终成功率误差”这句话，不符合这套数据处理流程的实际情况。
3. 真正需要补清楚的是：正文里的 `93.19 +/- 0.37%` 只是 3 次独立实验之间的离散，不是把所有标定系统误差都完整传播后的总误差预算。

## 2. `l=8` 确实很弱，这不是想象出来的

三次独立 run 的 `S88` 分别是：

- Run 1: `3.94%`
- Run 2: `3.87%`
- Run 3: `3.57%`

它们的均值大约是 `3.79%`，相对标准差大约是 `5.06%`。

作对比：

- `S55` 的相对标准差大约是 `2.33%`

更重要的是，把 3 次标定矩阵的对角元平均以后，可以看到检测效率基本随 `l` 增大一路下降：

- `l=0`: `11.00%`
- `l=1`: `19.49%`
- `l=2`: `17.54%`
- `l=3`: `14.79%`
- `l=4`: `11.50%`
- `l=5`: `9.10%`
- `l=6`: `7.08%`
- `l=7`: `5.39%`
- `l=8`: `3.79%`

所以很直接地说：

`l=8` 不只是“单独差一点”，而是整个检测链路对高阶模越来越不友好的最终结果。

## 3. 为什么 `l=8` 会这么弱

这件事最容易讲清楚的说法是：

### 第一层：高阶模本来就更大

第四章已经明确写了，LG 模的空间尺寸会随模式阶数增大，近似按 `sqrt(N)` 变大；对于 `p=0` 的纯角向模，就是近似按 `sqrt(|l|+1)` 变大。

这意味着：

- `l` 越大，光斑越大
- 光斑越大，还原端 SLM 的对准越敏感
- 光斑越大，在有限有效面积上的截断风险也越高

第四章还明确说明，在第五章这个 FP 腔实验里，不能像 Bell 态实验那样对不同模式用不同束腰去“压平”尺寸，因为必须保持与 FP 腔本征模同一个固定束腰，否则会引入束腰失配和额外的径向寄生模。

所以：

高阶模在第五章这套实验里先天就更难测，不是后处理造成的。

### 第二层：更主要的问题是 SMF 耦合

第五章的满载检测链路写得很清楚：透射光是经过“还原 SLM + 4f 中继 + 单模光纤耦合”来读出的。

这意味着测量最后一定要过一道 `SMF`。

而文献里对这个问题其实已经讲得很明白了。

- 在 [强度平坦技术.pdf](/D:/自制软件/1.thesis/My_nju_thesis-master/My_nju_thesis-master/参考文献/径向模式问题/强度平坦技术.pdf) 对应的文章 *Measuring azimuthal and radial modes of photons* 里，作者直接指出：传统 phase-flattening 虽然是标准方法，但存在 `mode-dependent losses`，高阶 OAM 模检测会更不高效。
- 这篇文章还进一步说明：造成这个问题的关键之一，就是 `SMF` 带来的额外高斯因子。它会改变模式正交投影的重叠关系，所以高阶模更容易吃亏。
- 他们提出 intensity-flattening，本质上就是想把这个 `SMF` 的高斯影响“拉平”，说明这个问题在文献里本来就是公认存在的，不是你这里独有的问题。

所以更朴素地说：

高阶模就算相位被还原了，最后能不能顺利耦合进 `SMF`，仍然会越来越难。

### 第三层：振幅调制全息图本身也会带来模式依赖的效率差异

这不是拍脑袋猜的，文献里也有支持。

- 在 [Exact solution to simultaneous intensity.pdf](/D:/自制软件/1.thesis/My_nju_thesis-master/My_nju_thesis-master/参考文献/径向模式问题/Exact%20solution%20to%20simultaneous%20intensity.pdf) 里，Bolduc 等人明确说明：amplitude masking 本身就是有损的，衍射效率取决于全息图的编码方式。
- 他们在投影测量实验里还专门对不同 hologram 的反射/衍射效率做归一化，否则不同全息图之间的效率差异会直接混进测量结果。

所以：

不同 `l` 的全息图，本来就可能有不同的有效转换效率。这会进一步把“高阶模更难测”的趋势加重。

## 4. 为什么 `l=1` 反而比 `l=0` 更好，这并不奇怪

这个现象不需要硬解释成“数据有问题”，它本身就可以是正常的。

最自然的解释是：

测量链路里“最适合耦合”的那个高斯有效光腰，不一定正好落在 `l=0`，也可能落在一个稍微更大的尺寸附近。这样一来：

- `l=0` 还没有到最舒服的位置
- `l=1` 反而更接近这个最佳点
- 到了 `l=2`、`l=3` 以后又开始继续偏离，于是效率重新下降

我用一个最简单的模场重叠模型做了定性检查，结果确实支持这种可能性：

- 如果接收端的最佳高斯尺寸稍微偏大，`l=1` 的理想耦合可以高于 `l=0`
- 但再往上走，`l=2`、`l=3`、`l=4` 之后又会继续下降

所以“`l=1` 比 `l=0` 更好”并不破坏整体规律，它更像是检测链路最佳耦合尺寸稍微偏移后的一个局部小峰值。

## 5. 这说明 `l=8` 弱主要是测量系统的问题，不是 FP 腔本体突然坏了

把前面的信息合起来，最朴素的判断就是：

1. 高阶模尺寸更大，检测端更难对准，也更容易受有限面积影响。
2. 更主要的是，phase-flattening 之后再进 `SMF`，高阶模天然更容易有 mode-dependent loss。
3. 振幅调制全息图本身也会让不同 `l` 的转换效率不一样。

所以 `l=8` 的低效率和较明显串扰，更像是检测链路的综合结果，而不是 FP 腔本体在 `l=8` 突然出现了一个完全不同的物理机制。

这也正是为什么标定矩阵是必要的：

它的目的本来就不是“让数据变好看”，而是尽可能把检测系统对不同通道的不公平剥离掉。

## 6. 那为什么“25 倍放大”这句话不能直接成立

因为论文最后报告的主对角成功率，不是绝对功率，而是每一列归一化之后的百分比。

也就是说：

- `S88` 变动时，反演出来的 `x88` 绝对值确实会明显变化
- 但最后画热图、算成功率时，还要再做列归一化
- 所以绝对功率里的那种敏感性，不会原封不动地传到最终百分比结果上

我实际做的敏感度检查结果是：

### 情况 A：只改 `S88`

如果把 `S88` 故意改坏 `10%`：

- 整体平均成功率只变化大约 `-0.028` 到 `+0.015` 个百分点
- `l=8` 自己的成功率变化大约 `-0.884` 到 `+0.901` 个百分点
- `x88` 的绝对值会变化大约 `-9.07%` 到 `+11.08%`

### 情况 B：整列 `S[:,8]` 一起改

如果把整列 `S[:,8]` 故意改坏 `10%`：

- 整体平均成功率只变化到 `0.01` 个百分点量级
- `l=8` 自己的成功率变化大约 `-0.685` 到 `+0.695` 个百分点
- `x88` 的绝对值变化大约 `-9.09%` 到 `+11.11%`

这组结果说明得很清楚：

`l=8` 的绝对反演功率确实比较脆，但论文最后报的“主对角百分比成功率”没有审稿人说得那么夸张。

## 7. `93.19 +/- 0.37%` 到底该怎么理解

这个地方一定要说清楚。

聚合工作簿 `triplicate_full9_aggregate.xlsx` 的 meta 已经写明，误差条来自 3 次独立 run 之间的统计离散。

所以：

正文里的 `93.19 +/- 0.37%` 更准确的含义是：

> 3 次独立实验最终平均成功率的 run-to-run 离散

它不是：

> 已经把弱通道标定系统误差完整传播进去之后的总误差预算

这就是 Q3 里真正需要补的地方。

## 8. 最稳妥的外部说法

如果后面要对外写回复，我建议用下面这层意思：

> 我们同意高阶弱通道 `l=8` 是最敏感的检测信道，其低效率主要来自检测链路对高阶模越来越不利，包括高阶模尺寸增大、phase-flattening 后的单模光纤耦合损失增大，以及振幅调制全息图本身的模式依赖效率差异。标定矩阵正是为了去除这类测量系统偏差而引入的。进一步的敏感度检查表明，这些偏差首先显著影响的是绝对反演功率，而论文报告的分选成功率是列归一化后的百分比，因此其受影响程度明显小于简单按检测效率倒数估计的“25 倍放大”。不过，正文中的 `+/-0.37%` 只能理解为三次独立实验之间的统计离散，不能直接当作完整系统误差预算。
