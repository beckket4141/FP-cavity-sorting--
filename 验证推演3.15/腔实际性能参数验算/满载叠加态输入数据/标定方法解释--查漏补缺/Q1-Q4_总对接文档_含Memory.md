## 3. 到目前为止，哪些结论已经比较稳

### 3.1 关于 Q1

Q1 不是“模型根本不成立”，而是写法太压缩，容易让人误会。

更准确的对象是：

- 单个锁频条件下：`y^(j) = S x^(j)`
- 全部锁频条件合起来：`Y = S X`

也就是说：

- `x` 不是一个脱离锁频条件的静态“全局唯一向量”
- 正确对象应当是逐锁定态的列向量族 `x^(j)`

这个结论在 [Q1定义澄清_详细报告.md](/D:/自制软件/1.thesis/My_nju_thesis-master/thesis/验证推演3.15/腔实际性能参数验算/满载叠加态输入数据/标定方法解释--查漏补缺/Q1定义澄清_详细报告.md) 里已经完整展开。

### 3.2 关于 Q2

Q2 的正确理解不是“标定对不对”，而是“标定出来的纯模参考响应，能不能沿用到满载时的离共振漏透”。

当前最稳的结论是：

- 你的标定方法本身是对的。
- 用“实测峰位 + 单模峰值透射率 + Airy 失谐系数 + 同一组标定矩阵 `S`”去前向预测满载原始读数 `Y`，和真实数据符合得很好。
- 这说明对当前这组 9 模实验数据来说，“离共振漏透主要是幅度变小，而不是横向模式轮廓完全换掉”这个解释是被数据支持的。

所以：

Q2 不能再从“你这套标定大概率根本不能迁移”这个起点重新假设。

### 3.3 关于 Q3

Q3 当前也已经有比较稳的落点：

- `l=8` 的确是最弱、最敏感的检测通道。
- 它弱主要是检测链路的问题，不是 FP 腔本体突然在 `l=8` 出现了新的坏物理。
- 更主要的物理原因是高阶模经还原后再进 `SMF`，phase-flattening 链路会出现越来越明显的 mode-dependent loss。
- 振幅调制 hologram 的模式依赖效率、SLM 有限面积和对准容差，会进一步加重这个趋势。
- 但这种敏感性首先显著影响的是“绝对反演功率”，不会按“检测效率倒数”那样粗暴地直接放大到论文最后的列归一化成功率百分比上。
- 正文中的 `93.19 +/- 0.37%` 只能解释成 3 次独立 run 之间的统计离散，不能假装已经是完整系统误差预算。

## 4. 这些是后续绝对不能再乱假设的 Memory

这一部分最重要。

后续 agent 如果忽略这些背景，很容易重新走偏。

### Memory A：标定矩阵 `S` 的真实测量定义

这是用户反复强调过的，不能再说模糊话。

标定矩阵第 `k` 列的测量方式是：

1. 产生端 `SLM` 产生纯的 `l=k`
2. `FP` 腔锁定态也是 `l=k`
3. 在这个固定条件下，检测端遍历 `l=0~8` 全部通道

所以 `S_{ik}` 的含义是：

> 在“纯参考态 `l=k` 经 FP 共振透射后到达检测端”的条件下，检测通道 `i` 的有效读出响应。

这意味着：

- `S` 不是拍脑袋凑出来的经验矩阵
- 它本来就是为了剥离检测系统不均匀性而测的

### Memory B：产生端和测量端都用了振幅调制 hologram，这不是偶然

用户明确说明过：

- 为了产生比较纯的 `l` 态，产生端使用的是振幅调制全息图
- 测量端同样也采用相似思路来做模式还原/投影

所以：

后续不能再把“检测链路里为什么会有 hologram 模式依赖效率问题”说成一个奇怪的额外假设。

这恰恰是这套系统的真实工作方式。

### Memory C：第五章这套 FP 实验不能像 Bell 态实验那样对不同模式做自适应束腰

第四章已经明确说了：

- 高阶 LG 模尺寸会变大
- 自适应束腰可以把不同模式“压平”
- 但第五章 FP 腔实验不能这么做
- 因为这里必须保持和 FP 腔本征模同一个固定束腰，否则会引入束腰失配和额外径向寄生模

所以：

后续如果再有人说“为什么不直接把不同 `l` 都调成一样大”，这是不符合这套实验边界的。

### Memory D：`l=8` 检测效率低，主因更像 `SMF` 耦合，不是单纯 SLM 快占满

用户已经明确给出过自己的解释框架，而且当前分析支持这个框架：

- 高阶模尺寸按 `sqrt(|l|+1)` 变大
- 这会让还原端 SLM 对准更难、面积压力更大
- 但更主要的问题是：就算模式被还原了，高阶模进 `SMF` 也更难

当前更稳的排序是：

1. 主因：`phase-flattening + SMF` 的高阶 mode-dependent loss
2. 次因：高阶模尺寸变大带来的 SLM 对准/有限面积问题
3. 叠加因子：振幅调制 hologram 本身对不同模式的转换效率差异

后续 agent 不应再把“主要原因”写成“SLM 面积快占满”这种过窄说法。

### Memory E：`l=1` 比 `l=0` 更好不是异常

用户已经提出，而且当前定性检查支持：

- 检测链路最佳耦合的有效高斯尺寸不一定正好落在 `l=0`
- 可能稍微偏大
- 因而 `l=1` 反而更接近最佳点
- 从 `l=2` 开始再继续下降

所以：

后续不要把 `l=1 > l=0` 自动解读成“数据奇怪”或“标定出错”。

它可以是检测链路最佳耦合点偏移后的正常结果。

### Memory F：`+/-0.37%` 不能再被说成总系统误差

这是 Q3 已经锁定的结论。

正文里的 `93.19 +/- 0.37%` 是：

> 3 次独立 run 之间的统计离散

它不是：

> 已完整传播弱通道标定误差、检测系统误差、所有系统项后的总误差预算

后续 agent 若再把它说成“已经完整覆盖全部误差”，会直接把 Q3 又带回危险状态。

## 5. 目前最适合继续做的下一步：Q4

Q4 的原始质疑是：

> 附录里把 FP 腔在标定时说成“带通滤波后到达检测端的光场可视为纯目标模式”，但如果 `tau_min = 3.5`，最近邻模式离共振漏透大约仍有 `2%`，那标定时其实并非绝对纯净。

这会引出两个需要讲清的问题：

1. 这 `2%` 量级的最近邻漏透，在标定矩阵 `S` 中到底占多大分量？
2. 这件事会不会让校正后的 `ER_sum` 被轻微高估？

### 5.1 Q4 的推荐起点

后续 agent 建议先做下面这几步：

1. 重新核对第五章和附录里“纯目标模式”“带通滤波”这些表述出现在哪些句子。
2. 用当前已验证的 `Q2` 前向模型，定量算出标定条件下最近邻模式的理论漏透比例。
3. 检查这一小部分漏透被吸收到 `S` 后，对反演出来的 `ER_sum`、成功率、非对角项会造成多大量级的系统偏移。
4. 判断这件事更适合被说成：
   - “可忽略”
   - “存在但量级很小，不影响主要结论”
   - “应当在附录中诚实补一句说明”

### 5.2 Q4 时不能重新掉回去的坑

做 Q4 时要避免三个老坑：

1. 不要重新怀疑 Q2 整体是否成立  
   当前数据已经支持“离共振主要改幅度，不改横向轮廓”。
2. 不要把 Q4 说成“所以标定矩阵根本不能用”  
   Q4 讨论的是标定条件并非绝对纯净，不是说 `S` 完全无效。
3. 不要把 `2%` 最近邻漏透自动夸张成“会颠覆 93% 成功率”  
   需要先做量级分析，再下结论。
