# 光腰为0.88mm测得数据 腔参数重算报告

## 1. 主结果

- 参考主峰取 `l=0` 选中分支，峰心波长 794.995671 nm，峰心频率 377.099485084 THz。
- 方法 A 直接 FSR = 9.938668 GHz；方法 B 全局拟合 FSR = 9.931464 GHz；最终采用 A_direct，得到 FSR = 9.938668 GHz。
- `l=0` 主峰 FWHM = 310.859 MHz，对应实验精细度 `F = FSR/FWHM = 31.9717`。
- 全部选中高信噪比主峰的加权平均精细度为 32.2367，仅作交叉验证。
- 相对位置拟合得到 `k = 0.222502 ± 0.005781`；方法 B 联合拟合交叉验证 `k = 0.222539`。
- 熔融石英折射率取 `n(20.18 °C) = 1.453799786`，`n(20.00 °C) = 1.453798267`，温度修正 `Δn = 0.000001519`。
- 由晶体腔公式反推得到 `L = 10.374279 mm`，`L/R = 0.414043`，`R = 25.056058 mm`。

## 2. 一致性检查

- Rising/Falling 直接 FSR 差异见 `fsr_estimates.csv`；当前采用理由：Method A selected because rising/falling direct FSR agree within 1%。
- `k` 拟合逐阶位置见 `k_fit_summary.csv`。`l=9` 仍与 `l=0` 发生近重合，但全局分支选择后残差保持在可追踪范围。
- 原始数据与补全后数据交叉验证的平均峰心偏移约为 0.000000 nm，平均 FWHM 偏移约为 0.000 MHz。

## 3. 与论文正文当前参数比较

- 当前正文名义参数：`L = 10.25 mm`，`R = 25.0 mm`，`k ≈ 0.221`，`F ≈ 29.8`。
- 本次重算相对正文的差值为：`ΔL = 0.124279 mm`，`ΔR = 0.056058 mm`，`Δk = 0.001502`，`ΔF(l=0) = 2.1717`。

- `raw_final_comparison.csv`：补全前后峰心、线宽和峰值变化。
