# 主峰归一化位置与解析 2/9 分支对比

## 口径
- 理论分支固定采用 `k_th = 2/9 = 0.222222222`
- 对应几何比 `L/R = sin^2(pi k_th) = 0.413175911`
- 实测位置统一按本目录主分析结果中的 `FSR_final = 9.919386 GHz` 归一化
- 这里只比较 `pos = ((nu_l - nu_0)/FSR) mod 1`，与精细度 `F` 无关

## 数据集
- 数据集：`0p98mm`
- 分析来源：`FSR补全后数据`
- 结果目录：`FSR补全分析结果`

## 合并主结果
- merged 平均绝对偏差 = 0.001924 FSR
- merged RMS 偏差 = 0.002215 FSR
- merged 最大绝对偏差 = 0.004407 FSR
- merged 最大绝对偏差 = 43.719 MHz
- merged 最差峰是 `l=8`，其圆周最短残差 = -0.004407 FSR
- `l=9` 闭合点绝对偏差 = 0.002597 FSR

## Rising / Falling 交叉检查
- rising RMS 偏差 = 0.002115 FSR
- falling RMS 偏差 = 0.002400 FSR
- rising 最大绝对偏差 = 0.003388 FSR
- falling 最大绝对偏差 = 0.005427 FSR

## 说明
- 误差采用圆周上的最短距离：`delta = ((pos_meas - pos_th + 0.5) mod 1) - 0.5`
- 因而像 `l=9` 这种理论上回到 `0` 的点，会被正确记作“小偏差”，不会误算成接近 `1 FSR`
