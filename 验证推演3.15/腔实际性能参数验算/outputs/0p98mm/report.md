# 光腰为0.98mm测得数据 腔参数重算报告

## 1. 主结果

- 参考主峰取 `l=0` 选中分支，峰心波长 794.984910 nm，峰心频率 377.104589174 THz。
- 方法 A 直接 FSR = 9.919363 GHz；方法 B 全局拟合 FSR = 8.231459 GHz；最终采用 A_direct，得到 FSR = 9.919363 GHz。
- `l=0` 主峰 FWHM = 307.389 MHz，对应实验精细度 `F = FSR/FWHM = 32.2698`。
- 全部选中高信噪比主峰的加权平均精细度为 32.4555，仅作交叉验证。
- 相对位置拟合得到 `k = 0.142915 ± 0.005776`；方法 B 联合拟合交叉验证 `k = 0.413797`。
- 熔融石英折射率取 `n(20.18 °C) = 1.453799975`，`n(20.00 °C) = 1.453798456`，温度修正 `Δn = 0.000001519`。
- 由晶体腔公式反推得到 `L = 10.394468 mm`，`L/R = 0.188397`，`R = 55.173281 mm`。

## 2. 一致性检查

- Rising/Falling 直接 FSR 差异见 `fsr_estimates.csv`；当前采用理由：Method A selected because rising/falling direct FSR agree within 1%。
- `k` 拟合逐阶位置见 `k_fit_summary.csv`。`l=9` 仍与 `l=0` 发生近重合，但全局分支选择后残差保持在可追踪范围。
- 原始数据与补全后数据交叉验证的平均峰心偏移约为 0.000000 nm，平均 FWHM 偏移约为 0.001 MHz。

## 3. 与论文正文当前参数比较

- 当前正文名义参数：`L = 10.25 mm`，`R = 25.0 mm`，`k ≈ 0.221`，`F ≈ 29.8`。
- 本次重算相对正文的差值为：`ΔL = 0.144468 mm`，`ΔR = 30.173281 mm`，`Δk = -0.078085`，`ΔF(l=0) = 2.4698`。

- `peak_fit_summary.csv`：全部候选峰、选中峰和 raw/final 交叉验证峰。
- `selected_peak_summary.csv`：按 `l=0..9` 合并后的主峰、FWHM 和精细度。
- `raw_final_comparison.csv`：补全前后峰心、线宽和峰值变化。
- `peak_fits_overview.png` 与 `position_fit.png`：人工复核图。
