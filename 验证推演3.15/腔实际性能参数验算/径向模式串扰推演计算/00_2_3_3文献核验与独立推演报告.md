# 2.3.3 文献核验与独立推演报告

## 1. 结论先行

本次核验后的核心结论只有一句话：

**对理想 `LG_{p=0}^l` 入射而言，FP 腔真正匹配的是整族横模共享的复光束参数 `q`，也就是束腰大小、束腰位置和波前曲率；不是把不同 `l` 的亮环半径调成一样大。**

因此：

1. `LG_0^l` 公式里的 `w(z)` / `w0` 是高斯包络尺度，也是决定瑞利长度与发散基准的参数；它**不是**高阶涡旋亮环半径。
2. 对 `LG_0^l` 而言，高阶 `l` 的亮环半径和二阶矩半径确实会随 `l` 增大，但它们只是由同一个 `w(z)` 派生出的不同“光斑大小”定义，不是新的腔匹配束腰。
3. 如果输入端已经用复振幅全息图近似生成了纯 `LG_0^l(q_{\mathrm{cav}})`，那么“所有 `l` 用同一个 `w0`”正是合理做法。环会自然变大，但这不表示腔应该跟着改 `w0`。
4. 若强行采用 `w_l = w0/\sqrt{|l|+1}`，就是主动把基础 `q` 改小。对同一 FP 腔族而言，这会让目标 `LG_0^l` 耦合迅速下降。
5. `Yang2024` 与 `Sroor2020` 中的 `1/\sqrt{|l|+1}` 语句，属于 **phase-only / QP / VWP 生成端的 `p=0` 纯度补偿语境**，不能直接搬成“FP 腔高阶模普适匹配定律”。

脚本产出的数值结果和你的实验趋势一致：

- 理想模型下，`same w0` 对所有 `l` 都给出 `100%` 目标模耦合。
- 理想模型下，`w_l = w0/\sqrt{|l|+1}` 会使目标模耦合从 `l=1` 的 `79.01%`、`l=2` 的 `42.19%` 开始快速塌陷，到 `l=8` 仅 `0.01%`。
- 用一个“复振幅生成 + 有效孔径 + 轻微失配”的现实模型标定到第五章量级后，`same w0` 从 `0.9289` 下降到 `0.8307`，与实验 `0.9289 -> 0.8271` 高度一致。
- 同一现实模型下，`scaled w_l` 仍然迅速塌陷，`l=2` 只有 `0.3832`，`l=8` 约 `8.5e-05`。

## 2. 2.3.3 逐句核验

当前 `2.3.3` 关键语句位于 `chapters/ch02_lg_oam_theory.tex:303-321`。

### 2.1 重叠积分定义

原句要点：

> 任意外部光场注入 FP 腔时，其在腔内各本征模式上的激发系数由模式重叠积分给出。

判定：**文献直接支持**

依据：

- `Lasers_Book.pdf`, PDF p.706-707：Siegman 在 “Lens Laws and Gaussian Mode Matching” 中把 mode matching 明确表述为把一个具有给定 waist size 和 waist location 的 Gaussian beam，匹配进另一个 cavity/interferometer 所要求的 waist size 和 waist location。
- `Lasers_Book.pdf`, PDF p.848：当输入波不是自洽本征波时，可以展开成正确本征模与高阶模分量的叠加。

结论：

- 这一句可以保留。
- 但严格说应强调“对腔本征模基的投影/重叠”，而不只是“有一个 `w0` 参数”。

### 2.2 “理想匹配时只激发目标模”

原句要点：

> 入射光为纯 `LG_0^{l_target}` 且其束腰 `w_in = w0` 时，仅有 `c_{0,l_target} \neq 0`。

判定：**结论方向正确，但当前表述不够严谨**

原因：

- 若输入真的是目标腔模 `LG_0^{l_target}(q_{\mathrm{cav}})`，当然只有目标模被激发，这来自模正交性。
- 但“只说 `w_in = w0`”还不够，严格条件应是 **整个复光束参数匹配**，即 waist size、waist position、wavefront curvature 一起匹配。

文献依据：

- `Lasers_Book.pdf`, PDF p.706-707：mode matching 的对象是 waist size + waist location。
- `Lasers_Book.pdf`, PDF p.848：`q` 不同的输入波会展开成多个高阶模。

建议口径：

- 可写成“当输入场与目标腔模属于同一 `q` 参数、同一 `l` 子空间且横向振幅完全一致时，只有目标模被激发”。

### 2.3 “高阶 l 具有不同等效光斑尺寸，因此宽 l 范围完美匹配困难”

原句要点：

> 不同拓扑荷 `l` 的光束具有不同的等效光斑尺寸（`w_eff \propto \sqrt{|l|+1} w0`），固定放大倍率下很难全部模式完美束腰匹配。

判定：**文献语境不同，需改写为推断**

这里最大的问题不是“趋势错”，而是“`w_eff` 究竟指什么”没有交代清楚。

独立推导表明，对 `LG_0^l`：

$$
r_{\mathrm{peak}} = w(z)\sqrt{|l|/2},
$$

$$
r_{\mathrm{rms}} = w(z)\sqrt{(|l|+1)/2}.
$$

也就是说：

- 若说“亮环半径”，比例是 `\sqrt{|l|}`。
- 若说“二阶矩半径”，比例是 `\sqrt{|l|+1}`。
- 但二者都**不是** LG 解析式里的 `w(z)` 本身。

文献依据：

- `Lasers_Book.pdf`, PDF p.666：`w(z)` 被明确定义为 Gaussian spot size。
- `Lasers_Book.pdf`, PDF p.671：高阶 Gaussian mode 的 `q(z)` 和 `w(z)` 与基模相同。
- `Lasers_Book.pdf`, PDF p.720：Siegman专门把高阶模式的 spot size / divergence 当作“由 mode order 带来的尺寸与发散性质”，并没有说腔的基础 waist 参数要改成 `w/\sqrt{|l|+1}`。

因此：

- “高阶 `l` 的亮环/二阶矩尺寸更大，因此更容易受孔径、截断、对准影响”这句话可以成立。
- 但若把它写成“因此腔匹配束腰必须跟着改成 `w_l`”，那就是越界推断。

### 2.4 “束腰失配会把能量泄漏到 `p>0`”

原句要点：

> 束腰失配仍会向径向高阶态 `p>0` 泄漏能量。

判定：**文献直接支持，且独立推导完全成立**

依据：

- `Lasers_Book.pdf`, PDF p.848：若输入波的 `q` 值接近但不等于自洽值，则它可展开成正确本征模与高阶 HG/LG 分量的叠加。
- 这与“waist mismatch -> radial leakage”完全一致。

### 2.5 “`|c_{1,l}|^2 \propto ((1-\eta^2)/(1+\eta^2))^2`”

原句要点：

> 一阶径向串扰概率满足 `|c_{1,l}|^2 \propto ((1-\eta^2)/(1+\eta^2))^2`。

判定：**当前文献不足，且当前写法不够准确**

我在 `Lasers_Book.pdf` 对以下相关章节做了核查：

- PDF p.706-707：Gaussian mode matching
- PDF p.717-720：higher-order mode spot size / aperture
- PDF p.771：stable Gaussian resonator modes
- PDF p.848：q mismatch 与高阶模展开

没有找到这条公式以当前形式直接出现。

而对 **同一 `l`、输入为纯 `LG_0^l(w_{\mathrm{in}})`、腔目标基为 `LG_p^l(w_0)`** 的情况，直接积分得到的精确结果是：

$$
|c_{0,l}|^2 = \left[\frac{2\eta}{1+\eta^2}\right]^{2(|l|+1)},
\qquad \eta = \frac{w_{\mathrm{in}}}{w_0},
$$

$$
|c_{1,l}|^2
= (|l|+1)
\left[\frac{2\eta}{1+\eta^2}\right]^{2(|l|+1)}
\left(\frac{1-\eta^2}{1+\eta^2}\right)^2.
$$

因此当前正文那条式子最多只能看成：

- 在 `\eta \approx 1` 附近、只强调 mismatch 因子时的**比例缩放提示**；
- 不能当作这里问题的完整精确公式；
- 更不能稳稳地归到 `Siegman1986` 名下。

这是本次核验里最需要改口径的一处。

### 2.6 “径向寄生模是空间匹配不完美的必然结果”

判定：**结论可保留**

这句话在物理上是对的，只需要把前面失配公式写准。

更稳妥的说法是：

- 对同一 `l` 子空间而言，只要输入场与腔本征模的 `q` 参数不完全一致，就会在 `p=0,1,2,...` 上发生展开；
- 这些 `p>0` 分量对应不同总阶数 `N=2p+|l|+1`，因此在频谱上出现卫星峰或附加共振。

## 3. 文献真正说了什么

### 3.1 Siegman：腔匹配的是 q，而不是亮环半径

本次最关键的三条证据都来自 `Lasers_Book.pdf`。

1. `PDF p.706-707`  
   模式匹配的定义是把一个已知 waist size、waist location 的 Gaussian beam 匹配进另一个 cavity/interferometer 要求的 waist size、waist location。  
   这说的是 **复光束参数**，不是亮环半径。

2. `PDF p.671`  
   Siegman 对高阶 Hermite-Gaussian mode 明说：`q(z)` 与 `w(z)` “exactly the same as for the lowest-order gaussian mode”。  
   LG 与 HG 只是圆柱/直角坐标下的同一族高阶 Gaussian mode 表示，因此这条逻辑同样适用于 LG 族。

3. `PDF p.848`  
   输入 beam 若 `q` 值接近但不等于 cavity 自洽值，就会展开成正确本征模加高阶 HG/LG 分量。  
   这正是“waist mismatch -> radial leakage”的书本依据。

所以，Siegman 给出的方向其实是：

- 同一稳定腔支撑的是一整族共享 `q_{\mathrm{cav}}` 的高阶 Gaussian mode；
- 高阶模式的横向尺寸会变，但基础 `q` 不随 mode order 改写成 `w_l`。

### 3.2 Karimi 2007 + Sephton 2016：phase-only 生成端天然带径向混模

`ol-32-21-3053.pdf`：

- `PDF p.1`：HyGG 用 `w0` 作为 beam waist 定义。
- `PDF p.2`：若只在 `TEM00` 腰斑面上乘一个 `e^{i m\phi}` 相位因子，则得到的是 HyGG，并可展开成同一 `m`、不同 `q` 的 LG 叠加。

`ao-55-28-7830.pdf`：

- `PDF p.1-2`：phase-only 变换缺少 LG 的振幅项，因此 power 会分散到多个 radial mode。
- `PDF p.1` 摘要与 `PDF p.2` 都明确说：**complex amplitude modulation** 可以克服这个问题。

这两篇文献共同支持：

- `Yang2024` 面临的根本问题首先是“phase-only 生成不纯”，不是“FP 腔应该去匹配一个新的 `w_l`”。

### 3.3 Sroor 2020：`1/\sqrt{|l|+1}` 是最佳分解尺度，不是腔匹配定律

`s41566-020-0623-z.pdf`, `PDF p.4`：

- 他们把 externally created modes 的分解尺度调到
  `w_{\mathrm{opt}}/w_0 = 1/\sqrt{|l|+1}`，
  并明确说明这是为了 **maximize the power content of the `p=0` mode**。

这句话的对象是：

- “外部生成模式在 LG 基下的 `p=0` purity / decomposition scale”。

它没有说：

- “对于同一个 FP 腔，真实的高阶 LG 腔模应该把基础束腰改成 `w_l = w_0/\sqrt{|l|+1}`”。

### 3.4 Yang 2024：作者自己也承认这是生成端问题，而且 SLM 会更好

`tmp_yang2024.pdf` 的关键三段非常重要：

1. `PDF p.4`  
   QP 只能调相，因此从高斯出发生成的是 HyGG；并给出同 `l`、不同 `p` 的 LG 展开。

2. `PDF p.4-5`  
   他们写得很清楚：随着 `l` 增大，`p=0` 权重下降；按 Ref. 34 的建议把尺度改成  
   `w_0' = w_0/\sqrt{|l|+1}`  
   可以提高 `p=0` 权重和对应 transmission。

3. `PDF p.5-6`  
   他们又明确说：这种做法会带来 input mode 与 cavity mode 的 mismatch；并且如果把 Q-plates 换成实现 amplitude-phase modulation 的 SLM，那么随着 `l` 增大，模式 purity 会一直更高，FP1 transmittance 还会进一步提高。

这三点加起来，结论非常明确：

- `Yang2024` 从头到尾讨论的是 **phase-only 生成端的纯度-耦合折中**。
- 这篇文献不能拿来证明“纯 LG 输入时，FP 腔高阶模应该匹配 `w_l = w_0/\sqrt{|l|+1}`”。
- 相反，文中自己都在暗示：若换成 amplitude-phase modulation，问题会显著缓解。

## 4. 独立推导

### 4.1 `w(z)`、束腰、光斑大小、发散角到底是什么关系

对腰斑面 `z=0` 的 `LG_0^l`，可写成

$$
u_{0,l}(r,\phi;w_0)
=
\sqrt{\frac{2}{\pi |l|!}}\frac{1}{w_0}
\left(\frac{\sqrt{2}\,r}{w_0}\right)^{|l|}
\exp\!\left(-\frac{r^2}{w_0^2}\right)e^{i l\phi}.
$$

这里：

- `w0` 是高斯包络尺度在束腰面处的值；
- `w(z)` 是它传播到一般 `z` 面时的对应尺度；
- `z_R = \pi w_0^2 / \lambda` 由 `w0` 决定；
- 因而 `w0` 也决定了该模式族的基本发散参数。

但对高阶 `l`，常见的“光斑大小”至少有两种：

1. **亮环半径**

   令强度

   $$
   I(r)\propto r^{2|l|}\exp\!\left(-\frac{2r^2}{w^2}\right),
   $$

   则极大值满足

   $$
   r_{\mathrm{peak}} = w\sqrt{|l|/2}.
   $$

2. **二阶矩半径**

   由

   $$
   \langle r^2\rangle = \frac{|l|+1}{2}w^2
   $$

   得

   $$
   r_{\mathrm{rms}} = w\sqrt{\frac{|l|+1}{2}}.
   $$

所以：

- 高阶 `l` 的“亮环变大”是真的；
- 高阶 `l` 的“二阶矩宽度变大”也是真的；
- 但这两者都不等于“LG 公式里的 `w0` 变成了 `w_l`”。

### 4.2 高阶 l 的“发散更大”是什么意思

在远场 `z \gg z_R`，

$$
w(z)\approx \frac{\lambda z}{\pi w_0}.
$$

于是

$$
\frac{r_{\mathrm{rms}}}{z}
\approx
\frac{\lambda}{\pi w_0}\sqrt{\frac{|l|+1}{2}}.
$$

这说明：

- 若用二阶矩角宽来描述，高阶 `l` 的确“看起来更发散”；
- 但它的增长来自 mode order；
- 不是因为 cavity family 的基础 `w0` 应该变成 `w_0/\sqrt{|l|+1}`。

换句话说：

- **束腰参数** 与 **高阶模式的环尺寸/二阶矩尺寸** 不是同一个概念。

### 4.3 纯 LG 入射时，FP 腔到底匹配什么

设输入与腔目标模都在同一腰斑面比较，且同一 `l`。两者仅 waist 尺度不同：

$$
u_{0,l}(w_{\mathrm{in}}), \qquad u_{0,l}(w_{\mathrm{cav}}).
$$

直接积分得振幅重叠

$$
c_{0,l}
=
\left[
\frac{2 w_{\mathrm{in}} w_{\mathrm{cav}}}
{w_{\mathrm{in}}^2 + w_{\mathrm{cav}}^2}
\right]^{|l|+1}
=
\left[
\frac{2\eta}{1+\eta^2}
\right]^{|l|+1},
\qquad
\eta=\frac{w_{\mathrm{in}}}{w_{\mathrm{cav}}}.
$$

所以目标模耦合功率是

$$
|c_{0,l}|^2=
\left[
\frac{2\eta}{1+\eta^2}
\right]^{2(|l|+1)}.
$$

立刻得到两个结论：

1. `same w0`：若 `\eta=1`，则对所有 `l` 都有 `|c_{0,l}|^2=1`。
2. `scaled w_l`：若 `\eta = 1/\sqrt{|l|+1}`，则耦合随 `l` 快速下降。

脚本 `ideal_overlap_summary.txt` 给出的具体值：

| `l` | `same w0` | `scaled w_l` |
|---|---:|---:|
| 0 | 100.00% | 100.00% |
| 1 | 100.00% | 79.01% |
| 2 | 100.00% | 42.19% |
| 3 | 100.00% | 16.78% |
| 4 | 100.00% | 5.29% |
| 8 | 100.00% | 0.01% |

这已经足以解释你实验里为什么一旦按 `w_l = w0/\sqrt{|l|+1}` 去做，透射会明显腰斩甚至更差。

### 4.4 一阶径向串扰的精确表达式

再把输入 `LG_0^l(w_{\mathrm{in}})` 投影到腔基 `LG_1^l(w_{\mathrm{cav}})`，直接计算得到

$$
c_{1,l}
=
\sqrt{|l|+1}
\left[
\frac{2\eta}{1+\eta^2}
\right]^{|l|+1}
\frac{1-\eta^2}{1+\eta^2},
$$

因此

$$
|c_{1,l}|^2
=
(|l|+1)
\left[
\frac{2\eta}{1+\eta^2}
\right]^{2(|l|+1)}
\left(
\frac{1-\eta^2}{1+\eta^2}
\right)^2.
$$

这比正文当前写法多了两层重要信息：

- 有一个显式的 `(|l|+1)` 因子；
- 还有一个来自 `p=0` 总重叠的前乘因子。

所以当前正文那条 `|c_{1,l}|^2 \propto ((1-\eta^2)/(1+\eta^2))^2` 若要保留，最多只能写成“近匹配极限下的缩放趋势”，不能当作这里的完整精确结果。

## 5. 数值结果与第五章闭环

### 5.1 理想模型

`01_ideal_lg_fp_overlap.py` 的结果说明：

- 若输入已经是纯 `LG_0^l(q_{\mathrm{cav}})`，那么同一 `w0` 下所有 `l` 都是完美耦合。
- 高阶 `l` 的亮环变大并不会自动要求 cavity 改 `w0`。
- `scaled w_l` 的主要后果不是“更好匹配高阶模”，而是把目标模耦合直接做坏。

### 5.2 现实模型

`02_generator_to_fp_model.py` 里我把两类情形分开算了：

1. **Bolduc / 复振幅全息图情形**  
   用接近纯 `LG_0^l` 的输入，再加有效孔径与轻微失配。  
   `same w0` 的预测从 `99.36%` 缓慢降到 `88.85%`；  
   `scaled w_l` 则从 `77.67%`、`40.99%`、`16.10%` 一路快速塌陷。

2. **Yang / phase-only 情形**  
   实际 cavity 耦合随 `l` 很快下降；  
   但若把分解基的尺度改成 `1/\sqrt{|l|+1}`，则“最佳拟合 `p=0` 权重”会从  
   `l=1: 77.29% -> 90.73%`、  
   `l=2: 48.73% -> 79.64%`  
   这样明显提高。  
   这正好说明了：**它解释的是生成端 purity，不是实际 cavity target overlap。**

### 5.3 与第五章实验数据对照

`03_compare_with_ch5_data.py` 读取了三次 `透射率.xlsx`，得到：

- 实验：`l=0` 为 `0.9289 ± 0.0071`
- 实验：`l=8` 为 `0.8271 ± 0.0242`

在把模型按实验 `l=0` 基准缩放后：

- 复振幅 `same w0`：`0.9289 -> 0.8307`
- 复振幅 `scaled w_l`：`0.9289 -> 0.000085`

这与实验的关系非常清楚：

- 你的实验明显支持“**same w0 + 高阶模式缓慢受孔径/失配影响**”；
- 明显不支持“**高阶模应该按 `w_l=w0/\sqrt{|l|+1}` 去做腔匹配**”。

这也是为什么你会看到：

- 同一 `w0` 时到 `l=4` 仍接近 `90%`，到 `l=8` 仍有 `80%+`；
- 但一旦按 `w_l=w0/\sqrt{|l|+1}` 去输入，`l=1,2` 就明显腰斩。

## 6. 最终判断：2.3.3 哪些能保留，哪些必须降级

### 6.1 可以保留

1. 重叠积分是描述外部光束注入腔本征模激发系数的正确工具。

## 7. 回答你的原问题

### 7.1 FP 腔匹配的 `w` 到底是什么

是 **复光束参数 `q` 所对应的基础高斯包络尺度**，即束腰大小、束腰位置和传播曲率；不是“亮环半径”。

### 7.2 光斑大小和束腰是不是一回事

不是。

- 束腰 `w0`：LG 模公式里的基本尺度参数。
- 光斑大小：必须先说明你指的是 `r_peak`、`r_rms`、`1/e^2` 半径还是别的定义。

### 7.3 高阶 l 模的束腰是什么，光斑大小又是什么

对同一 LG 模族 `LG_0^l(w0)`：

- 束腰参数仍是同一个 `w0`；
- 亮环半径是 `r_peak = w0\sqrt{|l|/2}`；
- 二阶矩半径是 `r_rms = w0\sqrt{(|l|+1)/2}`。

### 7.4 它如何和 FP 腔匹配

若输入真的是纯 `LG_0^l`，则它与腔匹配时应保持和腔本征模同一个 `q_{\mathrm{cav}}`。  
此时高阶模的环自然更大，但这不是失配。

### 7.5 FP 腔匹配的到底是高阶 l 的光斑大小还是束腰大小

**匹配的是束腰参数 / `q` 参数。**  
高阶 `l` 的光斑大小变化只是同一 `q` 模族内部的横向分布后果。

### 7.6 为什么你的实验同一 w0 高，而缩腰修正会塌

因为你的系统属于 **复振幅全息图近似纯 LG 输入**，不是 `Yang2024` 那种 `QP/VWP phase-only` 输入。

所以：

- 同一 `w0`：保住了与 cavity family 的 `q` 匹配，透射高。
- `w_l=w0/\sqrt{|l|+1}`：主动破坏了 `q` 匹配，目标模耦合迅速下降。

这与你第五章的数据完全一致。
