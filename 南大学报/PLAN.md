# 南京大学学报稿件计划：稳定双镜 FP 腔中 LG 模式分束的统一框架与误差机理

## 当前决策

本文采用“LG 分束入口 + 横模阶数内核 + Airy 串扰闭环”的路线。

对外叙事回到学报读者熟悉的物理对象：

- 稳定双镜 FP 腔中的 LG 模式分束。
- Gouy 相位依赖共振提供保态频谱选择。
- 平凹腔、对称双凹腔和一般稳定两镜腔属于同一设计框架下的不同几何实现。
- 径向寄生与卫星峰解释作为实验相关的物理闭环。

正文内部保留准确的物理分组变量：

- 各向同性稳定 FP 腔的横模共振位置由横模阶数 `N=2p+|l|+1` 决定。
- OAM 序列是 `p=0`、单符号 `l` 情形下的特例。
- 单个各向同性 FP 腔不单独区分 `+l` 与 `-l`。

性能分析采用正常的 FP 腔 Airy 透射路线：

- 周期 Airy 透射函数。
- 有限维串扰求和和热图可视化。
- 分选成功率 `eta_sort` 与串扰指标 `ER_sum`。
- 容量边界与大 `M` 极限。

一句话中心论断：

> 本文研究稳定双镜 FP 腔中的 LG 模式分束；由于各向同性稳定腔的横模共振位置由 `N=2p+|l|+1` 决定，单腔分束首先表现为按横模阶数的模式组选通，而 Airy 透射函数给出有限线宽下的串扰性能和容量边界。

## 稿件定位

目标期刊为《南京大学学报（自然科学）》。稿件定位为一篇稳妥型中文理论与仿真论文，不是 OE 主文翻译，也不是附录扩写。

核心贡献写成四层：

1. **统一设计语言**：用有效归一化 Gouy 步长 `k_eff` 描述稳定双镜 FP 腔中的折叠谱排布。
2. **构型实现**：平凹腔和对称双凹腔具有不同几何回代关系，且对称双凹不是平凹作 `L -> 2L`。
3. **定量性能闭环**：Airy 透射函数给出有限维串扰、`eta_sort`、`ER_sum`、容量边界和大维度极限。
4. **误差机理解释**：轴对称失配主要产生同一 `l` 子空间内的径向寄生项，卫星峰可由相同 `N` 简并解释。

## 正文结构

正文采用 6 节结构。

1. **引言**
   - 从 LG/OAM 空间模式、保态分束需求和 FP 腔频谱选择切入。
   - 自然引出稳定各向同性 FP 腔中横模阶数 `N=2p+|l|+1` 的作用。
   - 贡献段按“Gouy 折叠谱、Airy 串扰性能、构型实现、寄生峰解释”组织。

2. **稳定双镜 FP 腔的 Gouy 相位折叠谱框架**
   - 给出 `nu_{q,N}=FSR(q+N k_eff)`。
   - 给出一般稳定两镜腔 `k_eff=arccos(sqrt(g1 g2))/pi`。
   - 区分折叠谱排布层和几何回代层。
   - 保留平凹、对称双凹和小几何比 `sqrt(2)` 结论。

3. **连续模式组的最小间距景观与最优排布**
   - 定义连续模式组 `S_M={1,...,M}` 和 `s_min(k)=min ||qk||`。
   - 写明解析最优 `k*=m/M`、`gcd(m,M)=1`、`s_min=1/M`。
   - Farey/层级细化作为景观结构解释，不作为全文主轴。

4. **Airy 透射下的有限维串扰、性能指标与容量边界**
   - 从周期 Airy 透射函数出发。
   - 构造有限维串扰求和和热图。
   - 定义 `eta_sort`、`ER_sum`。
   - 给出 `M=9, F=32.21, k=2/9` 的理论数值例。
   - 推出 `tau_min=F s_min`、`M<=floor(F/tau0)` 和大 `M` 极限。
   - 末尾回到几何实现层，说明 `M=9` 时平凹偏向 `m=2`、对称双凹偏向 `m=4`。

5. **OAM 序列、径向寄生与卫星峰来源**
   - 将 OAM 连续序列作为 `p=0`、单符号 `l` 的特例处理。
   - 明确单个各向同性 FP 腔不区分 `+l/-l`。
   - 保留轴对称失配导致同一 `l` 子空间内径向泄漏的推导。
   - 用 `LG_1^4` 与 `LG_0^6` 同为 `N=7` 解释卫星峰。

6. **结论**
   - 收束到“Gouy 相位折叠谱设计 + Airy 串扰性能 + 几何实现 + 径向寄生解释”。
   - 不新增未展开的未来工作。
